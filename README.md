# BookTown

**本を通じて、人と出会うSNS。** 一人ひとりが自分の本屋を開き、その本屋が並んで街になります。本番は https://booktown.page です。

## 開発する人へ

読む順番:

1. [CLAUDE.md](CLAUDE.md) — 守る決まりの要点と、詳しい資料への案内
2. [docs/README.md](docs/README.md) — 資料の索引（どれが今の決まりで、どれが昔の記録か）
3. [docs/開発の引き継ぎ.md](docs/開発の引き継ぎ.md) — 開発の手順、作るときの規格、手元の確かめ、取り込みの注意

今だれが何を作っているか、作る機能の順番、取り込みの了承の決まりはリポジトリの外にあります（docs/README.md「リポジトリの外にあるもの」）。

## 起動

Node.js 22.13 以降と pnpm 11 を用意してください。

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5173 を開きます。Supabase の設定がないときは、ブラウザの中だけで動くデモの街になります（保存先は localStorage の `book-town-v1`。初めの街に戻すときは、このキーだけを消します）。手元の確かめとブラウザの通し確認の流し方は [docs/開発の引き継ぎ.md](docs/開発の引き継ぎ.md) にあります。
