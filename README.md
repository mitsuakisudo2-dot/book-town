# Book Town

**本を読みたくなるSNS。** 読書家が作る小さな個人書店を巡り、本と人に出会う、操作できる第1段階のプロトタイプです。

読書の終わりを、交流の始まりに。あなたの愛した一冊が、誰かの愛する一冊になる。

## 起動

Node.js 22.13以降（動作確認: 24.19）とpnpm 11を用意してください。

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5173 を開きます。スマホとPCのレイアウトに対応しています。

```sh
pnpm lint
pnpm typecheck
pnpm test:domain
pnpm build
```

この実行環境でのTurbopackのローカル処理制限を避け、ビルドにはNext.jsの正式なWebpackオプションを使っています。ビルドすると `out/` に静的サイトが生成されます。本番サーバーやデータベースなしでホスティングできます。

ブラウザの操作テストは、開発サーバーを起動した状態で `pnpm test:browser` を実行します。既定ではmacOSのGoogle Chromeを使います。他の環境では `BOOK_TOWN_CHROME` にChromium系ブラウザの実行ファイルを指定してください。`BOOK_TOWN_URL` でテスト先、`BOOK_TOWN_QA_OUTPUT` で結果保存先を変更できます。

## 試せる体験

- 6つのデモ書店を巡る。ジャンル・タイトル・著者・書店・店主を検索し、書店をフォローする。
- 木製の2D棚で、背表紙と面陳を眺める。本を選び、店主のPOPと紹介を読む。
- 本の詳細から、同じ本を置く別の書店を探す。異なるPOPを読み、該当する棚へ移動する。
- 自分の書店を作り、名前・紹介・看板の色を変更する。名前を付けた公開／非公開の棚を追加する。
- 24冊のサンプルから本を追加し、削除・並び替え・面陳への変更・POPの編集を行う。
- 棚は20スペース。背表紙は1、面陳は3を使用し、上限を超える追加や変更はできない。
- マウス・長押しタッチ・キーボードでドラッグ＆ドロップ。スマホでは本を選んで「左へ／右へ」でも移動できる。
- プロフィール、3×3の「人生の9冊」、公開本棚を閲覧する。自分の9冊は空欄を残して、選択・並び替え・コメントを編集できる。
- 読みたいリスト、フォロー、書店、プロフィールの変更は、このブラウザに保存される。

初回は「気ままに一軒、のぞいてみる」→本を選ぶ→「この本を並べるほかの書店」→別の棚→店主のプロフィール、と歩いてみてください。「自分の書店」からあなたの選書を並べられます。

## データと設計

Next.js App Router、React、TypeScript、Tailwind CSS、dnd-kitを使用しています。書棚・表紙・看板はCSS/SVGによるオリジナルデザインです。実在書籍の表紙画像は使用していません。店主・書店・POPは架空のデモデータです。

- `src/app/`: App Routerの画面と静的ルート生成
- `src/components/`: 街・書棚・編集・プロフィールなどのUI
- `src/lib/types.ts`: Book / Reader / Shop / Shelf / ShelfItem、容量計算
- `src/lib/data.ts`: サンプルデータ
- `src/lib/repository.ts`: 保存・復元・検証を担うデータアクセス層
- `src/lib/store.ts`: 更新処理とReact購読。容量制限をデータ更新時にも検証
- `tests/`: 容量・保存・整合性の検証と実ブラウザの操作テスト

保存キーは `book-town-v1`。UIから直接localStorageを扱わず、`TownRepository`を介します。将来Supabaseへ移行するときは、この境界を非同期データアクセスに拡張し、認証された利用者のIDに紐付く永続化へ置き換えます。今回の「公開」はデモ内の閲覧可否であり、実際に他の端末へ共有する機能ではありません。

保存できないブラウザでは、その状態を画面に表示します。不正な保存データは検証して初期状態へ戻します。初期データへ戻したい場合は開発者ツールから、このサイトの `book-town-v1` だけを削除してください。

## 今後

第2段階ではSupabase・認証・複数端末同期・書店と棚のアクセス権を実装します。書籍検索APIやカスタム登録を追加し、実際の選書を広げられます。公開時には通報・ブロック・権利確認・運用設計を用意します。決済・販売・コメント・チャット・AI選書は今回の実装範囲に含めていません。

旧プロトタイプからの変更履歴は、このプロジェクトのGitに保持しています。
