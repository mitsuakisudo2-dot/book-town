# Book Town

**本を読みたくなるSNS。** 読書家が作る小さな個人書店を巡り、本と人に出会う、操作できるフロントエンドのプロトタイプです。

読書の終わりを、交流の始まりに。あなたの愛した一冊が、誰かの愛する一冊になる。

## 起動

Node.js 22.13以降（動作確認: 24.19）とpnpm 11を用意してください。

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5173 を開きます。スマホとPCのレイアウトに対応しています。

```sh
pnpm lint
pnpm typecheck
pnpm test:domain
pnpm build
```

この実行環境でのTurbopackのローカル処理制限を避け、ビルドにはNext.jsの正式なWebpackオプションを使っています。ビルドすると `out/` に静的サイトが生成されます。本番サーバーやデータベースなしでホスティングできます。

ブラウザの操作テストは、開発サーバーを起動した状態で `pnpm test:browser`（既存機能）と `pnpm test:street`（街の散歩）、`pnpm test:feedback`（本の前景・リアクション）、`pnpm test:social`（タイムライン・レビュー）、`pnpm test:app`（下のバー・検索・読書・お知らせ・本の登録）を実行します。既定ではmacOSのGoogle Chromeを使います。他の環境では `BOOK_TOWN_CHROME` にChromium系ブラウザの実行ファイルを指定してください。`BOOK_TOWN_URL` でテスト先、`BOOK_TOWN_QA_OUTPUT` で結果保存先を変更できます。

## 試せる体験

- ホームの「書店」タブで6つのデモ書店を縦に眺める。各書店は小さなカードで、店主と最初の公開棚を1段だけ見せる。ほかの棚は「この書店へ」から書店のページで見る。ジャンル・タイトル・著者・書店・店主で絞り込み、書店をフォローする。
- 横に棚を眺め、タップすると同じ画面で本を手に取る。冒頭のあらすじと店主のPOPを読み、左右のスワイプ・横スクロール・矢印キー・前後ボタンで、その棚の隣の本へ移る。
- 本を閉じると元の縦位置・棚の横位置・フォーカスへ戻る。背景はモーダル表示中操作できない。
- 街を巡り終えると正直に終わりを示し、架空の追加店舗や活動で水増ししない。
- 本を開いたまま、その店主のほかの選書と、同じ本を置く別の書店の実際の棚を横に眺める。そこで別の本を手に取ってもページ移動は不要。公開棚だけを表示し、読了・読書中とは推定しない。
- POPに「いいね」「読む！」「私も好き！」を付ける。反応は書店・棚・展示ごとに独立し、このブラウザだけに保存される。
- 本の「読みたい」「お気に入り」を別々に保存し、自分のプロフィールでまとめて眺める。ほかのプロフィールには表示しない。
- 「購入する」からAmazon／楽天ブックスのタイトル・著者検索を別タブで開く。決済・販売・在庫取得は行わない。
- 自分の書店を作り、名前・紹介・看板の色を変更する。名前を付けた公開／非公開の棚を追加する。
- 24冊のサンプルから本を追加し、削除・並び替え・面陳への変更・POPの編集を行う。
- 既存の試作値として棚は20スペース、背表紙は1、面陳は3。上限を超える追加や変更はできない。棚数・容量の最終仕様は未決定。
- マウス・長押しタッチ・キーボードでドラッグ＆ドロップ。スマホでは本を選んで「左へ／右へ」でも移動できる。
- プロフィール、3×3の「人生の9冊」、公開本棚を閲覧する。自分の9冊は空欄を残して、選択・並び替え・コメントを編集できる。
- 下のバー（スマホ）は左から「ホーム」「検索」「読書を開始」「プロフィール」。右上のベルからお知らせを開く。
- ホームは「書店」と「タイムライン」をタブで切り替える。棚の上のスワイプは棚の横スクロール、それ以外の場所での左右スワイプはホームの切り替えとして扱う。
- 右下の丸いボタンから投稿する。アイコンはプロフィールの「設定」で万年筆・タイプライター・羽根ペンから選べる。投稿に添える本はタイトル・著者・ISBNで検索して選ぶ。
- 「検索」で本と書店を探す。何も入力していないときは「話題の本」（投稿の多い本）、「人気の本」（多くの棚に並び、読みたくなった人が多い本）、「棚の隅の本」（まだあまり知られていない本）を並べる。
- 「読書を開始」で「一人で読む」か「みんなで読む」を選ぶ。本は選ばなくても始められる（初期値は読んでいる途中の本）。読書時間を記録し、読書中にメモ・つぶやきを書ける。一人で読むときのメモは自分だけに見え、みんなで読むときのつぶやきはタイムラインにも流れる。読書の画面では、どの本を読んでいるかに関わらず、みんなの読書中のつぶやきが見え、いいねできる。いま「みんなで読む」にしている人と人数、同じ本を読んでいる人も見える。いま読んでいるデモの読書家は架空のデモデータ。
- プロフィールに投稿数・フォロー・フォロワー・読書時間を表示する。プロフィール・書店の編集、バーコード（またはISBN入力）での本の登録、読みたい本・お気に入り・登録した本の一覧を開ける。バーコードの読み取りはBarcodeDetectorに対応したブラウザのみ。書籍情報はopenBDから取得を試み、取れないときはタイトルと著者を手で入力する。表紙はオリジナルの仮デザインで描く。
- お知らせは、このブラウザの中の出来事（自分の投稿への返信、フォロー中の人の投稿、読みたい本への感想、同じ本をみんなで読んでいる人）から作る。架空の通知で水増ししない。
- 「タイムライン」で自由に投稿する。本のことでも、そうでないことでもよい。本を添えた投稿は、その作品ページのレビューにも並ぶ。
- 作品ページのレビューに返信して会話する。返信に本を添えて「これが好きなら、こっちも」と薦められる。
- 本を添えた投稿に「ネタバレあり」の印を付けると、タイムラインとプロフィールでは本文を隠して表示し、「表示する」を押すと読める。作品ページでは「ネタバレあり」の扉の向こうに置かれる。読んだ人は「ネタバレでは？」と報告でき、報告した投稿はその人の画面で同じように隠れる（報告後の扱いは未決定）。
- 感想に「いいね」とは別の「読みたくなった」を押すと、その本が読みたいリストに入り、作品ページに「○○さんの感想で、読みたくなった本です」と残る。自分の投稿に付いた数は「あなたの感想で、N人が読みたくなりました」と表示する。
- プロフィールに、その人の投稿が並ぶ（ネタバレは隠して表示）。自分の投稿は削除できる。自己紹介の下にnote・YouTube・公式サイトなどのURLを5件まで載せられる（http/httpsのみ。別タブで開く）。
- デモの読書家の投稿・反応数は架空のデモデータ。あなたの投稿は他の端末や読書家には共有されない。
- 読みたい・お気に入り、POPへのリアクション、フォロー、書店、プロフィール、投稿・返信・投稿への反応は、このブラウザに保存される。

初回は街を縦に歩く→棚の本を選ぶ→隣の本へ→「この本を並べるほかの書店」→別の棚→店主のプロフィール、と歩いてみてください。「自分の書店」からあなたの選書を並べられます。

## データと設計

Next.js App Router、React、TypeScript、Tailwind CSS、dnd-kitを使用しています。書棚・表紙・看板はCSS/SVGによるオリジナルデザインです。実在書籍の表紙画像は使用していません。店主・書店・POPは架空のデモデータです。

- `src/app/`: App Routerの画面と静的ルート生成
- `src/components/`: 街・書棚・編集・プロフィールなどのUI
- `src/lib/types.ts`: Book / Reader / Shop / Shelf / ShelfItem、容量計算
- `src/lib/data.ts`: サンプルデータ
- `src/lib/repository.ts`: 保存・復元・検証を担うデータアクセス層
- `src/lib/store.ts`: 更新処理とReact購読。容量制限をデータ更新時にも検証
- `src/lib/social.ts`: タイムライン・レビュー・返信・ネタバレ・「読みたくなった」の集計
- `src/components/Social.tsx`: 投稿欄、投稿ボタン、投稿カード、タイムライン、作品ページのレビュー
- `src/components/HomeView.tsx`: ホームのタブとスワイプ判定
- `src/components/SearchView.tsx` / `ReadingView.tsx` / `NotificationsView.tsx`: 検索・読書・お知らせ
- `src/components/BookPicker.tsx` / `BarcodeRegister.tsx`: 本の検索選択、バーコード・ISBNでの登録
- `src/lib/reading.ts` / `notifications.ts` / `books.ts`: 読書時間の集計、お知らせの導出、ISBNの検証と登録した本
- `tests/`: 容量・保存・整合性の検証と実ブラウザの操作テスト

保存キーは `book-town-v1`。UIから直接localStorageを扱わず、`TownRepository`を介します。将来Supabaseへ移行するときは、この境界を非同期データアクセスに拡張し、認証された利用者のIDに紐付く永続化へ置き換えます。今回の「公開」はデモ内の閲覧可否であり、実際に他の端末へ共有する機能ではありません。

保存できないブラウザでは、その状態を画面に表示します。不正な保存データは検証して初期状態へ戻します。初期データへ戻したい場合は開発者ツールから、このサイトの `book-town-v1` だけを削除してください。

## 今後

方針と未決定事項は `docs/README.md` から参照してください。`03_Codex実装仕様_v0.1.md` を試作・検証の参考にしています。認証・共有DB・非公開付箋・推薦の重みなどは、別途範囲を合意して進めます。投稿・レビュー・返信・読書中のつぶやきは、このブラウザの中だけで動く試作です（`docs/05`・`docs/06`）。チャット・課金・AI選書は含みません。

320px・390px・1440pxのChromeで表示と操作を確認するテストを用意しています。合成タッチイベントによる方向判定テストは実機の指の操作と異なり、iPhone/Androidの実端末でのスワイプ干渉は引き続き確認が必要です。保存キーとバージョンは `book-town-v1` / 1 を維持しています。新しい保存項目がない旧データも、書店・プロフィール・読みたいを保持したまま復元します。

旧プロトタイプからの変更履歴は、このプロジェクトのGitに保持しています。
