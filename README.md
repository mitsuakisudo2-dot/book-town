# Book Town

**本を読みたくなるSNS。** 読書家が作る小さな個人書店を巡り、本と人に出会う、操作できるフロントエンドのプロトタイプです。

読書の終わりを、交流の始まりに。あなたの愛した一冊が、誰かの愛する一冊になる。

## 起動

Node.js 22.13以降（動作確認: 24.19）とpnpm 11を用意してください。

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:5173 を開きます。スマホとPCのレイアウトに対応しています。

```sh
pnpm lint
pnpm typecheck
pnpm test:domain
pnpm build
```

この実行環境でのTurbopackのローカル処理制限を避け、ビルドにはNext.jsの正式なWebpackオプションを使っています。ビルドすると `out/` に静的サイトが生成されます。本番サーバーやデータベースなしでホスティングできます。

ブラウザの操作テストは、開発サーバーを起動した状態で `pnpm test:browser`（既存機能）と `pnpm test:street`（街の散歩）、`pnpm test:feedback`（本の前景・リアクション）を実行します。既定ではmacOSのGoogle Chromeを使います。他の環境では `BOOK_TOWN_CHROME` にChromium系ブラウザの実行ファイルを指定してください。`BOOK_TOWN_URL` でテスト先、`BOOK_TOWN_QA_OUTPUT` で結果保存先を変更できます。

## 試せる体験

- ホームの縦スクロールで6つのデモ書店と、店主が選んだ公開棚を直接眺める。ジャンル・タイトル・著者・書店・店主を検索し、書店をフォローする。
- 横に棚を眺め、タップすると同じ画面で本を手に取る。冒頭のあらすじと店主のPOPを読み、左右のスワイプ・横スクロール・矢印キー・前後ボタンで、その棚の隣の本へ移る。
- 本を閉じると元の縦位置・棚の横位置・フォーカスへ戻る。背景はモーダル表示中操作できない。
- 旧書店一覧は「書店一覧」から切り替えられる。街を巡り終えると正直に終わりを示し、架空の追加店舗や活動で水増ししない。
- 本を開いたまま、その店主のほかの選書と、同じ本を置く別の書店の実際の棚を横に眺める。そこで別の本を手に取ってもページ移動は不要。公開棚だけを表示し、読了・読書中とは推定しない。
- POPに「いいね」「読む！」「私も好き！」を付ける。反応は書店・棚・展示ごとに独立し、このブラウザだけに保存される。
- 本の「読みたい」「お気に入り」を別々に保存し、自分のプロフィールでまとめて眺める。ほかのプロフィールには表示しない。
- 「購入する」からAmazon／楽天ブックスのタイトル・著者検索を別タブで開く。決済・販売・在庫取得は行わない。
- 自分の書店を作り、名前・紹介・看板の色を変更する。名前を付けた公開／非公開の棚を追加する。
- 24冊のサンプルから本を追加し、削除・並び替え・面陳への変更・POPの編集を行う。
- 既存の試作値として棚は20スペース、背表紙は1、面陳は3。上限を超える追加や変更はできない。棚数・容量の最終仕様は未決定。
- マウス・長押しタッチ・キーボードでドラッグ＆ドロップ。スマホでは本を選んで「左へ／右へ」でも移動できる。
- プロフィール、3×3の「人生の9冊」、公開本棚を閲覧する。自分の9冊は空欄を残して、選択・並び替え・コメントを編集できる。
- 読みたい・お気に入り、POPへのリアクション、フォロー、書店、プロフィールの変更は、このブラウザに保存される。

初回は街を縦に歩く→棚の本を選ぶ→隣の本へ→「この本を並べるほかの書店」→別の棚→店主のプロフィール、と歩いてみてください。「自分の書店」からあなたの選書を並べられます。

## データと設計

Next.js App Router、React、TypeScript、Tailwind CSS、dnd-kitを使用しています。書棚・表紙・看板はCSS/SVGによるオリジナルデザインです。実在書籍の表紙画像は使用していません。店主・書店・POPは架空のデモデータです。

- `src/app/`: App Routerの画面と静的ルート生成
- `src/components/`: 街・書棚・編集・プロフィールなどのUI
- `src/lib/types.ts`: Book / Reader / Shop / Shelf / ShelfItem、容量計算
- `src/lib/data.ts`: サンプルデータ
- `src/lib/repository.ts`: 保存・復元・検証を担うデータアクセス層
- `src/lib/store.ts`: 更新処理とReact購読。容量制限をデータ更新時にも検証
- `tests/`: 容量・保存・整合性の検証と実ブラウザの操作テスト

保存キーは `book-town-v1`。UIから直接localStorageを扱わず、`TownRepository`を介します。将来Supabaseへ移行するときは、この境界を非同期データアクセスに拡張し、認証された利用者のIDに紐付く永続化へ置き換えます。今回の「公開」はデモ内の閲覧可否であり、実際に他の端末へ共有する機能ではありません。

保存できないブラウザでは、その状態を画面に表示します。不正な保存データは検証して初期状態へ戻します。初期データへ戻したい場合は開発者ツールから、このサイトの `book-town-v1` だけを削除してください。

## 今後

方針と未決定事項は `docs/README.md` から参照してください。`03_Codex実装仕様_v0.1.md` を試作・検証の参考にしています。認証・共有DB・公開会話・非公開付箋・推薦の重みなどは、別途範囲を合意して進めます。今回の実装は街の散歩と本の前景が中心で、コメント・チャット・課金・AI選書は含みません。

320px・390px・1440pxのChromeで表示と操作を確認するテストを用意しています。合成タッチイベントによる方向判定テストは実機の指の操作と異なり、iPhone/Androidの実端末でのスワイプ干渉は引き続き確認が必要です。保存キーとバージョンは `book-town-v1` / 1 を維持しています。新しい保存項目がない旧データも、書店・プロフィール・読みたいを保持したまま復元します。

旧プロトタイプからの変更履歴は、このプロジェクトのGitに保持しています。
