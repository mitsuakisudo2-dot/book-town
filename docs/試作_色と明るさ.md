## 試せること

プロフィール →「設定」の一番上。

- **画面の色（試作）:** 深緑・藍・黄土・あずき・葡萄・墨。深緑は今の色、藍・黄土・あずきは店の色（`OpenShop.tsx` の `THEMES`）から、葡萄と墨は試作で足した。**6色の中身は仮。** 共有フォルダの開発計画に決まった6色があれば差し替える。
- **明るさ（試作）:**
  - 昼: 今の色。
  - 灯り: 昼と夜の間の、暖かく青みを抑えた紙。
  - 夜: 暗い紙に明るい文字。
  - 自動（端末に合わせる）: 端末のライト／ダークで昼か夜。開いたまま端末が替わっても追う。
  - 時刻で替える: 下の「太陽どおりに移る」。選ぶと、ほかの時刻の色を見るつまみ（試作だけ）が出る。
- 選んだものはこのブラウザに残る（`proto-palette-v1`、つまみは `proto-time-preview-v1`）。

## 太陽どおりに移る（時刻で替える）

- 日付と時刻から太陽の高さを天文の簡単な式で求める（`src/lib/proto-time.ts` の `sunAt`）。場所は日本の真ん中あたり（北緯36度・東経138度）で、位置情報は求めない。日の出・日の入りは実際と数分の差。
- 高さで色を決める（`tokensAt`）:
  - 15度より上: 昼
  - 夕方 15度→5度: 灯りへ、5度→地平線の下4度: 夕暮れへ（文字は濃いまま、紙が砂色へ沈む）
  - 下4度: 暗い側へ切り替え。宵の始まり（こげ茶の紙）→ 下10度で宵 → 下18度で深夜
  - 朝は同じ区切りを逆に、青みのある色でたどる（夜明け前 → 夜明け → 朝 → 昼）
- 明るい側と暗い側の中は、1分ごとに OKLab で混ぜて少しずつ移す。重さはほぼない（1分に1回、色の名前を書き替えるだけ）。
- 明るい側と暗い側の切り替えだけは、紙が中くらいの明るさになると黒い文字でも白い文字でも読めなくなるため、段差が避けられない。読める範囲で段差がいちばん小さい所（夕暮れ↔宵の始まり、夜明け（暗）↔夜明け（明））で切り替え、スクロールや指が止まって4秒たってから6秒かけて移る（動きを減らす設定ではすぐ）。
- 区切りの角度と、途中の色（朝・夕暮れ・宵の始まり・夜明け）は仮。

## 読める濃さ

- `tokens.css` の `@pair` のすべてを、6色 × 昼・灯り・夜で 4.5:1 以上にした。
- 時刻で替えるは、一年（5日おき）× 2分おき × 6色の約900万通りで 4.5:1 以上（いちばん低いのは 4.51）。確かめる計算は `protoEngine().tokensAt(date, palette)` を回せば作れる（試作では手元の使い捨ての計算で確かめ、テストには入れていない）。
- `tests/tokens.test.ts` は、まだ昼の深緑しか見ていない。本体に入れるときは、ほかの色と明るさも見るようにする。

## 試作でわかったこと

- **6色は入れやすい。** ホームの作り直した部分（`home.css`、`letter.css`）は色を `tokens.css` の名前だけで決めているので、値を替えるだけで変わる。
- **ただし、色を直接書いている所が多い。** 下のバーの選んだ項目（`street.css`）、「デモの街」の札（`globals.css`）、検索のタグ、書店のカードなど。試作では目立つ所だけ `proto-palette.css` で上から寄せた。
- **夜（と灯り、時刻で替える）は、ホーム以外の画面に作業がいる。** 書店のカード、検索のタグ、プロフィールの一部は昼の色のまま残る。上下のバーと、写真の上の見出し（夜でも昼の紙と墨のまま）は試作で寄せた。
- 書店めぐりは絵が主役で、色を替えてもほとんど変わらない。ポスターは自分の色を持つので変わらない。

## 本体に入れるとき

1. main から新しいブランチを切る。`config.ts` と `proto-palette.css` の上書きは移さない。
2. 色を直接書いている CSS を、`tokens.css` の名前に移す（画面ごと。夜を出すならホーム以外も）。
3. 6色・灯り・夜を `tokens.css` に置く（試作の `:root[data-palette]`・`[data-lamp]`・`[data-night]` の形のままでよい）。
4. 選びを保存する場所を決める（今は試作だけのこのブラウザ。本体なら `state.settings` やアカウントの設定）。
5. 時刻で替えるを入れるなら、`proto-time.ts` の仕組みを本体の形に書き直し、読める濃さの計算をテストにする。
6. docs/09 に決まりを書き、画面の確認（通しの確認）を足す。
