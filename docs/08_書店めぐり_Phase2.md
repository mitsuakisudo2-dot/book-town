# 書店めぐり Phase 2

Phase 1の独立した書店めぐりを拡張。完成イメージに近づける装丁、木目、POPと、自分の書店の小さな編集画面を実装した。一般的なカード一覧への置き換えはしていない。

## 試し方

1. `/walk/` で既存の6つのデモ書店を眺める。本、棚札、POPは独立した操作対象。
2. `/my-shop/` で自分の書店を作り、「店内をつくる」を開く。
3. 灯りの本屋／夜の書斎／窓辺の選書を選ぶ。看板、店主の言葉、棚札、棚の公開範囲、本の順番・面陳・背表紙、POP、飛行機・コーヒー・葉っぱのスタンプを編集する。
4. 本は既存カタログと登録済みの本から検索して追加できる。同じ書籍の複数配置はそれぞれ独立したPOPを持つ。
5. 「店内を保存」し、「店内を眺める」で `/walk/#mine` に入る。キャンセルは保存前の編集を破棄する。

書店めぐりはPhase 1の上下切り替え・有限の巡回・棚の拡大・本を手に取る操作を維持する。モーダル内のPOP切り替えは本の移動と衝突しない。

## 表示と素材

- `BookJacket` の `illustrated` オプションは書店めぐりと、その本の詳細だけに適用する。既存画面の装丁は維持する。
- オリジナルの仮装丁8種を1枚のWebPアトラスにまとめ、書名・著者はHTMLで重ねる。実在書籍の表紙は複製していない。`coverUrl` がある本は既存の許諾済み画像を優先し、取得失敗時に仮装丁へ戻る。
- 木目は単一のWebP素材を看板と棚の前面に使用する。本と棚を背景画像に描き込まない。背景・木材色・照明・紙の色はSceneのデータから決まる。
- POPと棚札・看板には [Yomogi](https://github.com/google/fonts/tree/main/ofl/yomogi) の軽量サブセットを使用する。SIL OFL 1.1の本文と著作権表示は `public/fonts/Yomogi-OFL.txt` に同梱する。ASCII、仮名、既存コンテンツの漢字を収録（1,054字、約201KB）。収録外の漢字は通常の明朝系フォントに戻り、文字を欠落させない。`font-display: swap` で初期表示を止めない。
- 追加素材は装丁534KB、木目475KB、フォント201KB。全書店で共有してキャッシュする。既存の背景画像も維持する。

## 正本と非破壊移行

`StoreScene` のschemaVersionは1のまま、任意の `ownerManaged` と `templateId` を追加した。`ownerManaged` のSceneがある書店では、そのSceneが**書店めぐりの正本**になる。

初回編集時に旧公開棚を配置へコピーし、旧非公開棚の本とPOPは非公開・未配置として保持する。保存成功前には切り替えない。保存時には旧Shopを `legacyBackups` に一度だけコピーする。旧キー `book-town-v1`、旧Shop、旧リアクションは変更しない。

`book-town-walk-v1` キーを継続利用し、保存形式を `{schemaVersion:2, walkState, sceneOverrides, legacyBackups}` に更新した。Phase 1のschemaVersion 1を読み、履歴・途中位置・反応・Sceneを保持してv2へ移行する。未知のバージョンや破損データは元文字列を保持し、上書きを禁止する。

自分の書店だけを編集できる。保存前にカタログ参照、配置境界、重なり、公開フラグなどを検証する。localStorageへの書き込みが成功した場合のみ編集内容を採用する。容量不足などの失敗時は編集画面と下書きを残し、以前の保存済みSceneを維持する。

## 本とPOPの保持

テンプレート変更や並べ替えは配置ID・POP IDを維持する。テンプレートの家具に入りきらない本は未配置へ戻し、POP・スタンプ・反応キーを保持する。棚から下ろした本も消去せず、「まだ並べていない本」から戻せる。非公開だった棚からテンプレート変更で移動した本は、自動で公開しない。

公開閲覧・他店POP検索は、明示的に公開された段と、配置済みで非公開でない本のみを対象にする。非表示の親家具の子も除外する。編集プレビューでは自分の非公開の本を確認できる。

SceneのPOPリアクションキーは `["scene", storeId, placementId]`。初回移行時に旧リアクションをこのキーへコピーし、既存のScene反応を上書きしない。POPを切り替えるとスタンプ・店主・リンク・反応状態もその配置に切り替わる。

## 現在の限界と次の段階

- 保存はこのブラウザだけ。共有DB・ログイン・他端末同期は未実装。公開フラグはこの試作内の閲覧範囲を決めるもので、インターネット上の投稿にはならない。
- Sceneの編集は書店めぐりへ反映する。従来の書店ページ・プロフィール・旧本棚エディタは旧Shelfを利用し、その変更と新Sceneは自動同期しない。旧データを破壊せず段階的に移行するための暫定境界。編集画面にも別保存と明示する。
- 家具の自由配置、ドラッグ、画像アップロード、サイズの変更、照明の詳細調整、追加のテンプレート・スタンプ登録画面は未実装。データと表示は分離されており、次の段階で追加できる。
- 仮装丁・書店素材は完成イメージを参考にしたオリジナル素材。参考画像の写真そのものを再現したものではない。実機iOS/Androidの触感・速度の確認は別途必要。

## 見た目の調整（2026-10-12・参考画像を受けて）

ユーザーが共有した完成イメージ（暖かい照明の書店、看板、黒板の棚札、手書きPOP）に近づけた。データ構造（家具→段→配置→POP）は変えていない。

- 上部：店主のアイコン・名前・@ID・自己紹介（2行）。右上にフォロー（書店のフォロー）と「…」メニュー（書店のページ、訪問履歴）。訪問履歴のボタンはメニューへ移した。
- 看板：店名に加えて書店の `tagline` を添え、山の線画を刻んだ木の看板にした。床置きのPOPは店主の言葉（書店の説明）と「— 店主名」の署名。
- 棚の名前のチップ：「すべて」と各棚の名前。選んだ棚を照らし、ほかの段を暗くする（並べ替え・絞り込みはしない）。
- 段の左に余白を取り、新しい棚の名前は黒板の棚札、同じ棚の続きの段には植木鉢・地球儀・本の山・ろうそくの小物を置く。余白は既定の配置データ（`SHELF_GUTTER`）で決まる。余白のない保存済みの店内は、従来どおり小さな札を本の上に出す。
- 面陳の本のPOPはテープ留めの紙のカードにし、「— 店主名」を添えた。
- 灯りと周辺減光、棚の枠を明るい木の色にした。右側の操作は丸いボタンの下に名前を出す。
- 参考画像にある「いいね数」などの数字は出していない（Phase 1の「人気の集計数は表示しない」を維持）。下部ナビゲーションも既存の5項目のまま。

## 検証

`pnpm test:customization-domain` と `pnpm test:customization` を追加。移行、非公開、テンプレート変更、配置順、POPの所属、未配置への退避、保存失敗、キャンセル、再読み込み、反応の保存先、スマホでの画面収まりを確認する。既存のdomain・walk・street・appとTypeScript・lint・静的ビルドも維持する。
