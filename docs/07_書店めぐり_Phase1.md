# 書店めぐり Phase 1（試作中）

設計案の承認後に実装。既存の本の街・タイムライン・書店編集の保存形式は保持する。

## 表示とデータ

`WalkView` は `orderedStores` と `initialStoreId` を受け取れる。未指定時は公開棚に本を持つ既存書店を利用し、`/walk/#書店ID` を入口にできる。

`StoreScene` はバージョン付きのオブジェクト一覧。家具、段、本の配置、POP、店主POP、看板、棚札、スタンプを独立した要素として持つ。本はBook IDを参照し、同じBookを何度でも配置できる。本のPOPの親はBookPlacementでありBookではない。

位置・寸法は親に対する割合。回転は物理的な角度として計算し、子の矩形からキャンバス上のポリゴンを求める。配置禁止領域と境界は回転込みで検証する。段の本の指定寸法はキャンバス単位で保持し、家具を縮めると再計算してあふれた配置を未配置へ戻す。

`woodScene` は木の書店の初期配置を作るテンプレートアダプター。4段はこのテンプレートの初期値であり、モデルの制約ではない。面陳、密集した背表紙、混合、平台の違いを既存デモ書店で表現する。密集デモには既存カタログの複数配置を利用する。新しい人・書誌・活動数は生成しない。

`Book.coverUrl` は任意。未指定・画像の読み込み失敗時は既存の仮装丁を表示する。背表紙は書名・著者・色から生成する。実在表紙は同梱していない。ローカル検証では書誌データに許諾済みURLを設定できる。登録書籍への永続的な表紙設定UIは未実装。

素材は `public/themes/woodshop/room.webp`。画像には背景だけを描き、本棚・本・POPはDOMで描画する。素材が読めない場合はCSS背景へ戻る。照明色、木の色、紙の色、背景の暗さ・ぼかしはデータから反映する。日本語手書きフォントは追加せず、既存の明朝系フォントを使用している。

## 家具を変更するデータ操作

`addBookPlacement` → `setBookPop` で一冊とPOPを作る。`moveFurniture` は家具の位置だけを変更。`resizeFurniture` は内部を再配置。`deleteFurniture` は本・POPを残し、本を未配置へ戻す。`placeBook` は同じ配置IDを別の段へ移す。`setRowStyle` は段ごとの展示方式・寸法・間隔を変更する。

これらは編集UIから独立した純粋関数。変更候補は `validateScene` で検証してから保存する。位置変更による禁止領域との衝突を、将来のエディタでそのまま確定しないこと。

本の隣への移動は同じ家具の上段から下段、各段の店主の順番。POP操作は本の移動から分離する。幅24px未満の背表紙は最初のタップで段を拡大。キーボードのEnterは直接本を開ける。

## 保存と互換性

旧保存キーとバージョン1は変更しない。旧ShelfItemからの配置IDはShop IDとItem IDを含み、元のShop／Shelf／Itemの反応先を保持する。旧エディタでの編集は派生表示へ反映する。

新キー `book-town-walk-v1` の形式は `{schemaVersion:1, walkState, sceneOverrides}`。巡回状態、店舗反応、独自配置のPOP反応を保存する。現時点の配置は既存データから生成し、独自編集用のsceneOverridesは保存往復できるが編集・適用UIはまだない。既存のsceneOverridesは巡回更新で消さず保持する。

破損または未知バージョンを読み込んだ場合、元の保存文字列を上書きせず、巡回はメモリ内で動作する。既存の読書データは影響を受けない。移行を追加する場合は旧データをコピーして検証し、保存成功を確認してから新形式を採用する。

## 巡回

セッション開始時に順番を固定。リンク指定を優先し、未完了のセッションがあれば再開する。新しい巡回では未訪問を先にする。公開されなくなった店を除外し、途中で新しい店を差し込まない。終了後は再巡回を明示的に選べる。

訪問の暫定条件は、前面に表示された3秒、または本・POPを開くこと。非表示タブの時間は除く。履歴・途中位置は削除でき、店舗反応は保持する。「店主に伝える」は送信されないデモ。人気の集計数は表示しない。

通常の店内はスクロールせず、詳細・全文モーダルだけ縦に読める。縦の書店移動、横の本移動、POP移動を別の入力範囲で扱う。モーダル中は店を切り替えない。現在の店だけを描画し、隣接背景を先読みする。
