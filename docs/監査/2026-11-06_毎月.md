3. **見張りが GitHub の予定だけに頼る（AUD-184→AUD-204）。** 60日で止まる心配（AUD-184）より先に、遅れが実際に起きた。案：GitHub の外で動くもの（けにーさんの机の Cloudflare Workers など）が本番と見張りの最後の時刻を見る。新しいサービスと費用はけにーさんが決める。それまでは知らせを「続けて遅れたとき」だけにする。
