## 作業の手順で気をつけること

- **取り込み:** けにーさんへの言葉は平易に（PR は「提案書」、merge は「本体に取り込む」）。取り込みは1本ずつです。了承が要るか、承認なしで取り込める軽微な直し・資料だけの変更かは、運用指針の4章と CLAUDE.md に従います。DB のマイグレーションは、main に入ると自動で本番に適用されます。
- **見直しの重さ:**
  - 小さな直し（画面が変わらない直し、確認の手順の直し、数行の直し）は見直し1回です。
  - DB、ログイン・お金・権限、ホームの大きな画面は、2人で見直します。
  - 迷ったら大きい側にします。

- **「戻る」の層（`src/lib/back-layer.ts`）:** 遅いスマホでは、離れた画面の片付け（React の passive effect のあと片付けと `setTimeout(0)`）が数秒待たされ、読書家が「戻る」で戻ってきたあとに走ることがあります。層を外す処理は、外した時から履歴が動いていないとき（`popstate` の数が同じとき）だけ段を消します。層の登録と片付けは `useLayoutEffect` で、画面を離れたその時に行います。確かめは `tests/app-journey.mjs` の「on a slow phone, 戻る from another page returns to the step left」（CPU を6倍遅くして、本屋を開く途中でホームへ出て戻る）。ただし、ページ自身が戻している途中（小窓を閉じてその段が外れるまで）の `popstate` は数えません。数えると、返信の小窓を閉じてすぐ便りのページを閉じたとき、便りが外れた段の上でもう一度開きます（2026-10-17、ホームの通しが CI で時々落ちていた原因。確かめは `tests/home-journey.mjs` の「a 便り's page: by keyboard…」で、小窓と便りを5ミリ秒の間に閉じる）。
