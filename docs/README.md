## 重要な読み方

- **決定**: ユーザーが明確に支持した方針。実装時に尊重する。
- **有力案**: 複数人が賛同しているが、試作・検証が必要な案。
- **提案**: 会議に出た案。承認済み要件ではない。
- **未決定**: 実装前に判断が必要な事項。

これらを混同しない。特に「1人2棚」「1棚15〜20スペース」「ホーム画面の詳細」「SNSの公開範囲」などは、最終仕様として固定されていない。

## Codexへの注意

- 最初にこの `docs/` とルート `AGENTS.md` を読むこと。
- **この文書を読んだだけで全機能を実装しないこと。** 作業指示された範囲に限って変更する。
- 現在のリポジトリは Next.js + React + TypeScript の個人書店プロトタイプ。既存機能・テスト・保存データを壊さない。
- 仕様が競合したらユーザーの明示的な最新指示を優先し、合意していない部分を決め打ちしない。
- 実装済み・モック・構想のみを区別して報告する。ブラウザで検証していないことを検証済みと書かない。
- 公開リポジトリにつき、個人情報・APIキー・秘密の設計情報を追加しない。
