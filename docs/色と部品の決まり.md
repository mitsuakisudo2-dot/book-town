# 色と部品の決まり

画面を作るときの色・文字・角・ボタンの決まりです（管理表の1番、2026-10-16）。新しい画面はここに書いたものだけを使います。

## どこにあるか

- **色・文字の大きさ・角・書体**: `src/app/tokens.css`。値はここにしか書きません。
- **ボタン・チップ・丸ボタン**: `src/app/parts.css`。試作 v37 の形です。
- **画面の色（6色）を選ぶ所**: 「わたし」の設定の「画面の色」。この端末に残ります（`src/lib/appearance.ts`、`src/lib/appearance-store.ts`）。

## 色

名前で使います。`#294b3e` のような値や `rgb()`、`white`・`black` は画面のファイルに書きません。

| 名前                          | 使う所                                                     |
| ----------------------------- | ---------------------------------------------------------- |
| `--paper`                     | 画面の地                                                   |
| `--sheet`                     | カードや小窓の地                                           |
| `--band` `--notice` `--pop`   | 帯、お知らせ、POP の地                                     |
| `--ink`                       | 文字                                                       |
| `--ink-2`（`--muted`）        | 控えめな文字（日付、説明）                                 |
| `--line` `--line-2`           | 線、枠                                                     |
| `--field`                     | 入力欄の枠                                                 |
| `--green`                     | ボタン、印、選んだ物。**読書家が選んだ画面の色**になります |
| `--on-green`                  | `--green` の上の文字                                       |
| `--green-soft`                | 選んだ物の淡い地                                           |
| `--on-photo`                  | 写真の上の白い札の文字                                     |
| `--forest` `--lamp` `--alert` | 森の緑、灯り、注意（消す・間違い）                         |

- 名前は `--green` のままですが、中身は選んだ色（深緑・煉瓦・藍・藤・山吹・墨）です。「選んだ物」「押せる物」の色は必ず `--green` にします。緑に見せたい飾りに `--green` を使うと、藍を選んだ人には藍になります。
- 淡い色や影は、名前を混ぜて作ります：`color-mix(in srgb, var(--green) 30%, transparent)`。
- 色を足すときは `tokens.css` に名前を足し、文字と地の組み合わせを先頭の `@pair` に書きます。6色すべてで 4.5:1 以上かをテストが確かめます。
- 6色が変えるのは `--green` `--on-green` `--green-soft` `--on-photo` の4つだけです。紙・文字・線は変わりません。
- 表紙、写真、ポスターのインク、本屋の絵（書店めぐりの店内など）は、色の決まりの外です。データとして持つ色は `src/lib/` に置きます。

## 文字

- 大きさは `--t-cap`（12px）〜 `--t-head`（22px）の名前で使います。**12px より小さい字は使いません。**
- 書体は `var(--sans)`（端末の字）と `var(--serif)`（題名・店の名前・見出し・引用・POP）。ポスターだけ `--poster-mincho` `--poster-gothic`。
- 日本語の段落に `text-wrap: pretty` は使いません（テストが止めます）。

## 角

`--r-tag`（4px、札）、`--r-box`（12px、ボタンや枠）、`--r-card`（16px、カード）、`--r-pill`（丸い端）。

## 部品（parts.css）

どれも指で押す所が 44px 以上あります。

| 部品          | 使う所                                                                                          |
| ------------- | ----------------------------------------------------------------------------------------------- |
| `.btn`        | ふつうのボタン（線だけ）                                                                        |
| `.btn.fill`   | その画面でいちばんしてほしいこと。1画面に1つまで                                                |
| `.btn.soft`   | 2番目に大事なこと（淡い地）                                                                     |
| `.btn.quiet`  | やめる・あとで（文字だけ）                                                                      |
| `.btn.danger` | 取り消せないこと（消す）。確かめる小窓の中では `.btn.danger.fill`                               |
| `.btns`       | ボタンを並べる行（狭いと折り返す）                                                              |
| `.chip`       | 少しの中から選ぶ（絞り込み、並び順）。選んだ物は `aria-pressed="true"` か `aria-checked="true"` |
| `.icon-btn`   | 絵だけのボタン（閉じる、戻る）。`aria-label` を付けます                                         |
| `.text-btn`   | 文の中の言葉のボタン（もっと見る）                                                              |

- 今ある画面の `.button` `.ghost` `.icon-button`（`globals.css`）は古い部品です。色は名前に置き換えました。大きさは、その画面を触るときに新しい部品へ移します。
- 部品にない形が要るときは、その画面の CSS で作り、色・大きさ・角は名前で書きます。何度も使う形になったら `parts.css` に移します。

## 自動の確認

`tests/tokens.test.ts`（`pnpm test:domain` と CI で走ります）:

- 文字と地の組み合わせが、6色すべてで 4.5:1 以上。
- 6色が決まった6つで、`tokens.css` に色ごとの段がある。
- **直書きの色と、12px より小さい字の数が増えたら止める。** 数はファイルごとに `tests/style-baseline.json` にあります（2026-10-16 の時点で色が約1,370か所、小さい字が約420か所）。新しいファイルは0から始まります。
- 画面を直して数が減ったら、テストが「数を下げて」と言います。`tests/style-baseline.json` のその行を新しい数にします（0なら行を消します）。減った数を戻せないようにするためです。
- 数を増やして通すことはしません。どうしても直書きが要るとき（絵の中の色など）は、理由をコメントに書き、PR で一言ことわってから数を変えます。

## 今ある直書きの直し方

まとめて置き換えはしません（管理表1番）。画面を触る開発で、その画面のファイルの直書きを名前に置き換え、`style-baseline.json` の数を下げます。昔の緑（`#365242` `#6f7f63` `#5f6f55` `#e9eedf` など）は、役目に合わせて `--green` `--ink-2` `--green-soft` `--line` に寄せます。
