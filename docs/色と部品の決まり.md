# 色と部品の決まり

画面を作るときの色・文字・角・ボタンの決まりです（管理表の1番、2026-10-16）。新しい画面はここに書いたものだけを使います。

## どこにあるか

- **色・文字の大きさ・角・書体**: `src/app/tokens.css`。値はここにしか書きません。
- **ボタン・チップ・丸ボタン**: `src/app/parts.css`。試作 v37 の形です。
- **画面の色（6色）を選ぶ所**: 「わたし」の設定の「画面の色」。この端末に残ります（`src/lib/appearance.ts`、`src/lib/appearance-store.ts`）。

## 色

名前で使います。`#294b3e` のような値や `rgb()`、`white`・`black` は画面のファイルに書きません。

| 名前                          | 使う所                                                     |
| ----------------------------- | ---------------------------------------------------------- |
| `--paper`                     | 画面の地                                                   |
| `--sheet`                     | カードや小窓の地                                           |
| `--band` `--notice` `--pop`   | 帯、お知らせ、POP の地                                     |
| `--ink`                       | 文字                                                       |
| `--ink-2`（`--muted`）        | 控えめな文字（日付、説明）                                 |
| `--line` `--line-2`           | 線、枠                                                     |
| `--field`                     | 入力欄の枠                                                 |
| `--green`                     | ボタン、印、選んだ物。**読書家が選んだ画面の色**になります |
| `--on-green`                  | `--green` の上の文字                                       |
| `--green-soft`                | 選んだ物の淡い地                                           |
| `--on-photo`                  | 写真の上の白い札の文字                                     |
| `--forest` `--lamp` `--alert` | 森の緑、灯り、注意（消す・間違い）                         |
| `--shade`                     | 影、写真を暗くする幕、小窓の後ろの幕（混ぜて使う）         |
| `--on-dark`                   | 写真の上や暗い幕の上の白い文字                             |

- 名前は `--green` のままですが、中身は選んだ色（深緑・煉瓦・藍・藤・山吹・墨）です。「選んだ物」「押せる物」の色は必ず `--green` にします。緑に見せたい飾りに `--green` を使うと、藍を選んだ人には藍になります。
- 淡い色や影は、名前を混ぜて作ります：`color-mix(in srgb, var(--green) 30%, transparent)`。
- **影と写真の幕には `--ink` ではなく `--shade` を混ぜます**（`color-mix(in srgb, var(--shade) 8%, transparent)`）。昼は `--ink` と同じ色ですが、夜は `--ink` が明るくなり、`--shade` は黒のままです。写真の上の白い文字・白い札の地は `--on-dark`（昼も夜も白）です。
- 本屋のテーマ色（`.theme-sage` などの `--theme` `--theme-light` `--theme-deep` `--theme-pale` `--theme-fill`）は本屋の顔で、`tokens.css` に昼と夜の両方があります。文字には `--theme-deep`、淡い地には `--theme-pale`、看板のように塗って上に白い字を置く所には `--theme-fill`（昼も夜も濃いまま）を使います。プロフィールの「〇〇さんの書店」の札は、その店の `--theme-light` から `--theme-pale` へのグラデーションで、店ごとに色が分かれます（2026-10-16 けにーさん「店ごとに分ける」）。札の字（`--theme-deep` `--ink` `--ink-2`）は、両端の色の上で昼も夜も 4.5:1 以上を `tests/tokens.test.ts` が確かめます。
- 色を足すときは `tokens.css` に名前を足し、文字と地の組み合わせを先頭の `@pair` に書きます。6色すべてで 4.5:1 以上かをテストが確かめます。
- 6色が変えるのは `--green` `--on-green` `--green-soft` `--on-photo` の4つだけです。紙・文字・線は変わりません。
- 表紙、写真、ポスターのインク、本屋の絵（書店めぐりの店内など）は、色の決まりの外です。データとして持つ色は `src/lib/` に置きます。

## 夜（明るさ）

設定の「明るさ」は「端末に合わせる・昼・夜」で、最初は「端末に合わせる」（v37 の仮）です。画面の色と同じ保存（`book-town-appearance-v1` の `{ palette, brightness }`、端末ごと）に入ります。

- 夜は `tokens.css` の `:root[data-theme="dark"]` と、色ごとの `:root[data-palette="…"][data-theme="dark"]` です。夜が変えるのは紙・文字・線・灯り・注意と、選んだ色の `--green` `--on-green` `--green-soft` です。`--on-photo` `--on-dark` は昼のままです。
- `<html>` の `data-theme="dark"` は、ページの頭の小さなスクリプト（`src/lib/appearance.ts` の `APPEARANCE_BOOT`）が最初に描く前に付けます。「端末に合わせる」の間は、町を開いたまま端末が暗く・明るくなっても追いかけます。設定で選んだときは `src/lib/appearance-store.ts` が付け替えます。
- 画面のファイルは名前を使っていれば夜に何もしなくてよいです。`--ink` を影や地に使うと夜に明るくなるので、影と幕は `--shade`、写真の上の字は `--on-dark` にします。
- 絵（木の棚、本の背、表紙、ポスター、書店めぐりの景色、読書家のアイコン）は夜も昼の色のままです。表紙に暗くする幕は掛けません。
- 時刻で替える・灯りの強さは、まだ決まっていないので作っていません。

## 文字

- 大きさは `--t-cap`（12px）〜 `--t-head`（22px）の名前で使います。**12px より小さい字は使いません。**
- 書体は `var(--sans)`（端末の字）と `var(--serif)`（題名・店の名前・見出し・引用・POP）。ポスターだけ `--poster-mincho` `--poster-gothic`。
- 日本語の段落に `text-wrap: pretty` は使いません（テストが止めます）。

## 角

`--r-edge`（2px、本の角や細い札）、`--r-tag`（4px、札・入力欄）、`--r-box`（12px、ボタンや枠）、`--r-card`（16px、カード・大きな面）、`--r-pill`（丸い端）。丸は `50%` のまま書きます（大きさではなく形なので）。

2026-10-17 に、それまでの12種類の角（1〜24px）をこの5段に寄せました（1〜3px→edge、4〜7px→tag、8〜14px→box、16〜24px→card、高さの半分の角だった物→pill）。

## 影

影は3段です。どれも `--shade` を混ぜるので、夜も黒い影のままです。

| 名前       | 使う所                                         |
| ---------- | ---------------------------------------------- |
| `--lift-1` | 小さく浮く物（ピン、札、小さなつまみ）         |
| `--lift-2` | カード、浮いているボタン、手に取った物の下の影 |
| `--lift-3` | 小窓、下から出る紙、画面の上に重なる大きな面   |

- 本の背や表紙の斜めの影、POP の紙の影、内側の線（`inset`）や選んだ輪（`0 0 0 3px`）は、絵や印なので段の外です。
- 段にない角と影の数も、色と同じく `tests/style-baseline.json` で数え、増えると止めます。

## 部品（parts.css）

どれも指で押す所が 44px 以上あります。

| 部品              | 使う所                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| `.btn`            | ふつうのボタン（線だけ）                                                                        |
| `.btn.fill`       | その画面でいちばんしてほしいこと。1画面に1つまで                                                |
| `.btn.soft`       | 2番目に大事なこと（淡い地）                                                                     |
| `.btn.quiet`      | やめる・あとで（文字だけ）                                                                      |
| `.btn.danger`     | 取り消せないこと（消す）。確かめる小窓の中では `.btn.danger.fill`                               |
| `.btns`           | ボタンを並べる行（狭いと折り返す）                                                              |
| `.chip`           | 少しの中から選ぶ（絞り込み、並び順）。選んだ物は `aria-pressed="true"` か `aria-checked="true"` |
| `.icon-btn`       | 絵だけのボタン（閉じる、戻る）。`aria-label` を付けます                                         |
| `.text-btn`       | 文の中の言葉のボタン（もっと見る）                                                              |
| `.text-btn.quiet` | 脇に置く言葉のボタン（外す、大きさを変える、本を登録・設定）                                    |

- 2026-10-17 に、画面ごとにあった約25種類のボタン（`.button` `.button.primary` `.button.secondary` `.text-button` `.icon-button`、本屋の編集の `.editor-button` など、スキャンや便りや本の手のひらの専用のボタン）を、上の部品に置き換えました（`.button` と `.button.primary` → `.btn.fill`、`.button.secondary` → `.btn`、`.text-button` → `.text-btn`、`.icon-button` → `.icon-btn`、気持ちの選択 → `.chip`）。古い名前を書くと `tests/tokens.test.ts` が止めます。
- 画面に合わせて部品の置き場所（余白、幅、並び）を変えるのは、その画面の CSS で `.その画面の名前 .btn { margin: … }` のように書きます。字の大きさ・角・押せる大きさは変えません（44px より小さくしない）。
- 部品にしていないのは、絵の一部として押す物です（書店めぐりの店内の棚や POP、本の背、ポスターのページ送り、通りの店先のフォロー、注釈モードの道具）。
- 部品にない形が要るときは、その画面の CSS で作り、色・大きさ・角は名前で書きます。何度も使う形になったら `parts.css` に移します。

## 自動の確認

`tests/tokens.test.ts`（`pnpm test:domain` と CI で走ります）:

- 文字と地の組み合わせが、6色すべてで、昼も夜も 4.5:1 以上。本屋のテーマ色の文字も、昼と夜で確かめます。
- 6色が決まった6つで、`tokens.css` に色ごとの段がある。
- **直書きの色と、12px より小さい字の数が増えたら止める。** 数はファイルごとに `tests/style-baseline.json` にあります（2026-10-16 の時点で色が約1,370か所、小さい字が約420か所）。新しいファイルは0から始まります。
- 画面を直して数が減ったら、テストが「数を下げて」と言います。`tests/style-baseline.json` のその行を新しい数にします（0なら行を消します）。減った数を戻せないようにするためです。
- `tests/home-journey.mjs` が、暗い端末で最初の描画から夜になることと、主な画面の字が夜も 4.5:1 以上で読めることを、6色で確かめます。
- 数を増やして通すことはしません。どうしても直書きが要るとき（絵の中の色など）は、理由をコメントに書き、PR で一言ことわってから数を変えます。

## 今ある直書きの直し方

2026-10-16、管理表58番（夜の下ごしらえ）で画面の枠の直書きをまとめて名前に置き換えました（約1,370か所から約340か所）。残りは絵の色（木の棚、本の背、書店めぐりの景色、本屋のテーマ色、ポスターのインク）です。これからは、まとめて置き換えはしません。画面を触る開発で、その画面のファイルの直書きを名前に置き換え、`style-baseline.json` の数を下げます。昔の緑（`#365242` `#6f7f63` `#5f6f55` `#e9eedf` など）は、役目に合わせて `--green` `--ink-2` `--green-soft` `--line` に寄せます。
