# SNS基盤の追加（モック）— feature/sns-feed

日付: 2026-10-11 / 実装: Claude / レビュー: ユーザー・ChatGPT
仕様と設計判断: [05_SNS基盤_仕様と設計判断.md](../05_SNS基盤_仕様と設計判断.md)

## 概要

本の街に加えて、TwitterやInstagramのように自由に投稿・交流できるSNSを、**このブラウザ内で操作できるモック**として追加しました。目指す体験は「この人の呟きが好きだから、この人が好きな本を読んでみたい」です。複数ユーザー間の共有・認証・通知は次の段階として切り分けています。

既存の本の街・書店・プロフィール・読みたいリストの動作と保存データは変えていません（既存のブラウザテスト37件・ドメインテスト16件はすべて通過）。

## 体験の流れ

1. `/feed/` タイムラインにデモの読書家6人の投稿が新しい順に流れる（「みんな」「フォロー中」）。
2. 感想の本カードから作品ページ `/books/[id]/#post-<id>` の該当感想へ。
3. 作品ページの「みんなの感想」から会話ページ `/posts/?id=` へ。返信に本を添えて薦められ、薦められた本の作品ページにも表示。
4. アイコン・名前からプロフィールへ。人生の9冊・個人書店・投稿一覧・人のフォロー。
5. 本のある投稿に「読みたくなった」。
6. その直後に「読みたいリストに追加」。経由した投稿を記録し、自分の読みたいリストに「○○さんの感想から」と表示。

## 変更点

### 新規
- `src/lib/social/` — SNSのドメイン層
  - `types.ts`: `Post`（自由投稿・本つき・感想・返信を1つの型で）、`BookLink.purpose`（mention / review / recommend）、反応・フォロー・ネタバレ報告、`SocialRepository` 境界

  - `format.ts`: 日本時間の絶対時刻表示
- `src/lib/routes.ts` — SNS画面のURL生成（サーバー化時の変更点を1か所に）
- `src/components/social/` — `FeedView` / `PostCard` / `Composer` / `PostDetailView` / `BookReviews` / `ProfileSocial` / `WishSourceNote` / `social.css`
- `src/app/feed/page.tsx`, `src/app/posts/page.tsx`
- `public/demo/*.svg` — デモ投稿用のオリジナルイラスト3点

## 検証結果

環境: Windows 11 / Node.js 22.23.3 / pnpm 11.25.0 / Next.js 16.4.0 / Playwright 1.64.0 / Google Chrome 154（ヘッドレス）。ブラウザテストは開発サーバー（`pnpm dev`）に対して実行。

| コマンド | 結果 |
|---|---|
| `pnpm lint` | 通過 |
| `pnpm typecheck` | 通過 |
| `pnpm test:domain` | 書店 16件・SNS 19件 通過 |
| `pnpm build` | 通過（静的ページ45件。`/feed`・`/posts` を含む） |
| `pnpm test:browser` | 10件 通過（既存） |
| `pnpm test:street` | 12件 通過（既存） |
| `pnpm test:feedback` | 15件 通過（既存） |
| `pnpm test:sns` | 16件 通過（新規。1440px・390px・320px、コンソールエラー・ハイドレーションエラーなし） |
| `prettier --check --end-of-line auto src tests package.json` | 通過 |

`test:sns` で確認していること:
- タイムラインにネタバレ本文がDOMごと出ないこと、作品ページで開閉できること、会話全体が一度に開くこと
- 感想 → 作品ページ → 投稿者プロフィール → その人の書店への移動
- 「読みたくなった」だけでは保存されず、追加すると `wishSources` に投稿IDが記録され、プロフィールの表示から元の投稿に戻れること
- 1600×1200の画像が1080×810のJPEGになり、代替テキストとともに保存されること
- 本を添えただけの投稿は感想欄に出ず、「感想として公開」は出ること
- 返信の推薦が薦めた本の作品ページに出ること
- フォロー中タイムライン、ネタバレ報告と取り消し、後からのネタバレ指定、削除、再読み込み後の保持、町の保存データに画像が入らないこと
- 390px・320pxで横スクロールが出ず、投稿画面が全画面で開くこと

### 未検証
- iPhone / Android の実機、Safari / Firefox
- スクリーンリーダーでの実際の読み上げ（ロール・名前・`aria-pressed` / `aria-expanded` はPlaywrightで確認）
- 実際のブラウザのlocalStorage容量超過時の挙動（上限による拒否は単体テストで確認）
- HEIC画像（ブラウザが読めない場合はメッセージを表示する実装）

### 既知の問題（変更前から）
- `out/` を素の静的サーバー（`python -m http.server`）で配信すると、Next.jsのセグメントprefetch（`__next.<segment>.__PAGE__.txt`）が全ルートで404になる。ビルドは `__next.<segment>/__PAGE__.txt` の階層で出力しており、`main` のビルドでも同じ。画面遷移は動き、`test:sns` の機能チェック15件は静的配信でも通過した。本番ホスティングでの扱いを確認したい。
