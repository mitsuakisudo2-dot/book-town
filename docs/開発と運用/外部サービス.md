# 外部サービス

本のデータと表紙に使う外のサービスについて、何に使ってよいか、何をしてはいけないか、出典をどう書くかの正本です。どう取ってくるか（聞く順、間隔、判定）は [本と書誌.md](../機能/本と書誌.md) にあります。ログインのメールと人間の確認（Resend、Turnstile）の鍵は [権限と鍵.md](./権限と鍵.md) にあります。

## 本のデータの取り元

- **書誌の取り元は、国立国会図書館と openBD だけ。** Amazon は保存が24時間までなので使えない。楽天の API は、取得したデータの公開保存を規約が認めていないので使わない。
- **楽天と Amazon は、購入（アフィリエイト）のリンクだけに使う。**

## 国立国会図書館

- NDL サーチの書誌（SRU と、OAI-PMH の毎日の差分と毎月の全件ファイル）は、図書館自身の書誌（`iss-ndl-opac` と作成中の `iss-ndl-opac-inprocess`）だけを使う。CC BY 相当で、商用でも申し込みは要らない。
- 2026-10-21 に国立国会図書館から、蔵書・全国書誌などの書誌データは目的を問わず申請なしで無料で使え、全件ファイルもあると返事があった（申請は要らない）。続けて使う人は利用申請フォームで知らせるよう頼まれている（協力のお願い。けにーさんが出す、監査 AUD-132）。
- 同時に何本も聞かない。SRU は20秒に1冊まで（[本と書誌.md](../機能/本と書誌.md)「書誌マスタ」）。

## openBD

- 書誌に使う所（題名、巻、シリーズ、著者、出版社、発売日）だけを残し、出版社が書いた紹介と著者紹介、表紙は残さない。
- 表紙はそのまま出し、削除の依頼に従う（[本と書誌.md](../機能/本と書誌.md)「表紙の削除依頼」）。

## Google Books

- 表紙だけに使う。Google の表紙には「powered by Google」と、その本の Google Books へのリンクを付ける。
- Google の答えはブラウザに残さない。
- API キーは Vercel の `NEXT_PUBLIC_GOOGLE_BOOKS_API_KEY` から読む（なくても動く）。

## 表紙の出し方の決まり

- 表紙は切り抜きも重ね描きもせず、そのまま出す。画像に手を加えたり、別の画像に差し替えたりはしない。
- 取得元は表紙の下に出す（「表紙: openBD」「powered by Google」）。

## 出典

- 出典は `/credits/` のページに1つにまとめ、本ごとの取得日は書かない（取得日から、その版のいちばん古い登録の日が分かってしまうため。[本と書誌.md](../機能/本と書誌.md)「書誌マスタ」）。国立国会図書館の書誌は「NDLサーチの API を利用」と書く。
- 本のページには、見出しの下、表紙の出典の次に小さく「書誌の出典」のリンクだけを置く（[本と書誌.md](../機能/本と書誌.md)「画面」）。
