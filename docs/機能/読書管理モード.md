# 読書管理モード

SNS を外して、自分と本だけで使う「読書管理モード」の決まりの正本です（管理表 97〜100）。決めた経緯と理由は共有フォルダの「読書管理モード_基本設計_2026-10-18」（けにーさん 10-18 決定）にあり、ここには今のコードがどう守っているかを書きます。だれが何を読めるかの全体は [公開範囲.md](./公開範囲.md)、DB の工事の書き方は [DBの変え方.md](../開発と運用/DBの変え方.md) にあります。

- 土台（98）は DB だけです（`supabase/migrations/20261207000000_reading_mode.sql`）。モードに入る画面、切り替えの置き場所、管理モードのホームは 99 で作ります。それまでは、だれも管理モードにも「公開プロフィールなし」にもなりません。
- 確かめは `pnpm test:db` の `tests/db-reading-mode.test.ts` です。

## 3つの状態

| 状態                             | 自分の記録・棚・統計                   | 人に届く新しい操作           | 他人から見えるもの                                           |
| -------------------------------- | -------------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| 管理モード                       | できる（新しい物は自分だけ）           | DB が断る                    | 公開プロフィールがあれば、通常モードで見せていた物がそのまま |
| 通常モード・公開プロフィールなし | できる（新しい物は自分だけ）           | 公開プロフィールを作ってから | 何もない                                                     |
| 通常モード・公開プロフィールあり | できる（新しい物は本人のはじめの範囲） | できる                       | 本人が決めた範囲のとおり                                     |

今の読書家は全員「通常モード・公開プロフィールあり」で、何も変わりません。

## モード

- `reader_settings.mode`（`normal`／`manage`）。本人だけが読み書きでき、行がなければ通常。切り替えはこの1列を書くだけで、ほかの行には触りません（何度往復しても、記録・棚・範囲が1つも変わらないことを試験で確かめています）。

## 公開プロフィール

- `profiles.published`。今あるプロフィールは全部 `true`。公開していないプロフィールはユーザーID（`handle`）が空でよく、名前も空でよい。公開するときに ID と名前が要ります（DB の制約）。
- 公開していない人は `private.is_hidden('profile', id)` が真になります。運営が隠した人を外している所（プロフィール、人生の9冊、投稿、記録、一緒に読む、書店、ポスター、本の題名が読めるか、街、検索、人数）は、全部そのまま公開していない人も外します。新しく人を出す所を作るときも、この関数を聞いてください。
- 公開をやめる操作は今はありません（読書家から送られたら断る）。距離を置くのは管理モードと退会です（仮決め、10-24。99 で見直せます）。

## 人に届く操作を断る

`private.reaches_people(人)`（公開プロフィールがあり、通常モード）が偽のとき、読書家からの次の書き込みを DB が断ります。断るときは `42501` で、ヒントが `booktown:reading_mode`（管理モード）か `booktown:no_public_profile`（公開プロフィールなし）です。行の値はエラーに出しません。

- 便り・返信・一緒に読むメモ（ひとりメモは断らない）
- いいね、読みたくなった（押し直しも）、POP への反応
- 人と書店のフォロー、書店へのいいねとひとこと（取り消しは断らない）
- 書店を開くこと、開いている書店の名前・言葉・見た目・公開の棚・店内を変えること（閉店と、閉じている書店の中は断らない）
- ポスターの貼り出しと、貼り出したポスターを直すこと（取り下げと削除は断らない）
- 一緒に読むこと
- 記録・本の読書の状態・ライブラリの棚の範囲を広げること

止めないもの：消す、範囲を狭める、閉店、フォローを外す、ブロックと解除、通報、ネタバレの報告、あとで行く、訪れた書店、退会。データベースの仕事（マイグレーション、夜の処理、`give_own_copy`）は断りません。

**仮決め（10-24、99 で見直す）**: 管理モードの間、開いている書店の棚や店内を変える保存は、狭める変更も断ります（閉店すれば変えられる）。貼り出したポスターも直せません。プロフィールの文と人生の9冊を変えることは止めていません。どれも 99 の画面と一緒に決めます。

画面の側（99 で作る）：断られた保存は、ほかのまだ送っていない変更を巻き込まないこと（保存の守り、AUD-002）と、古いタブには上のヒントで「管理モードに切り替わっています」と伝えること。

## 記録したときのモードと、新しい物の範囲

- `library_entries.added_mode`、`reading_entries.made_mode`、`reading_sessions.made_mode`、`library_shelves.made_mode`。DB が書き、アプリは書けません（`library_entries` と `library_shelves` は列の権限がなく、ほかはトリガーが元に戻す）。
- 管理モードの間と公開プロフィールがない間に作った記録・棚・本の状態は、アプリが何を送っても「自分だけ」で始まります。
- 本の読書の状態（読みたい・読書中・読了）は、本ごとに範囲を持ちます（`library_entries.audience` と `detail`、[公開範囲.md](./公開範囲.md)「見せる範囲」の4つ）。新しい本は本人のはじめの範囲（`status_audience`・`status_detail`）から始まり、はじめの範囲を狭めると今までの本も狭まります（記録と同じ）。

## 人数の数え方

- 決まりは `private.status_counted(本の行)` 1つです。返すのは、ほかの人の数に入る状態と読みたいか、または何も入らない。
  - 管理モードで入れた本は入らない。本人が手で公開にしても入らない（けにーさん 10-18 02:11Z）。
  - 通常モードで入れた本は、範囲が「人数だけ」以上の間だけ入る。「自分だけ」にすればその場で外れる。外した本も入らない。
  - 公開プロフィールのない人と、運営が隠した人は入らない。ブロックでは動かない。
- **外に見せている状態**（けにーさん 10-18 02:16Z）：通常モードで見せていた本を管理モードで変えても、外は通常モードで最後に見せた状態のまま（`status_held`・`shown_status`、`wanted_held`・`shown_wanted_at`）。通常モードでその本の状態か読みたいを次に変えたとき、今の状態がそのまま見えるようになります。管理モードで外した本はその場で外れ、管理モードで戻した本は何も見せません。
  - 本人の本のページに「外ではこう見えています」を出すかは 99 で決めます（この列で読めます）。
- 作品ごとに1人1回：`private.reading_counts(作品の配列)`（読みたい・読書中・読了の人数。同じ作品の版を2冊持つ人は、進んでいるほうで1回）。17「みんな」の面などの人数は、これを使う関数から出します。
- 本の行を写す工事（`give_own_copy` のような）を新しく作るときは、上の列も写してください。写さないと、写した行の記録時のモードが今のモードになります。

## 規約と13歳以上の確認

- 規約の版は `private.terms_versions`（運営が公開するときに書く、44 で作る。まだ1つもない）。`asks_again` が真の版は、それより前の版にだけ同意した人に聞き直します。
- 同意は `public.terms_consents`（人・版・日時・13歳以上か）。本人だけが読め、今の版にだけ同意でき、直せず消せず、退会で消えます。
- `public.terms_to_agree()` が、今同意してほしい版（なければ null）を返します。

## 99 で決めること

最初にモードを選ばせるか、切り替えの置き場所、管理モードのホームの並び、公開済みの物の一括非公開、SNS を始める手順（公開プロフィールを作る時機。公開していない人の退会の確かめ方を含む。今の退会の画面はユーザーIDを打たせる）。上の仮決め3つ。
