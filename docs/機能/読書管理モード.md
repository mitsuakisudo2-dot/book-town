# 読書管理モード

SNS を外して、自分と本だけで使う「読書管理モード」の決まりの正本です（管理表 97〜100）。決めた経緯と理由は共有フォルダの「読書管理モード_基本設計_2026-10-18」（けにーさん 10-18 決定）にあり、ここには今のコードがどう守っているかを書きます。だれが何を読めるかの全体は [公開範囲.md](./公開範囲.md)、DB の工事の書き方は [DBの変え方.md](../開発と運用/DBの変え方.md) にあります。

- 土台（98）は DB です（`supabase/migrations/20261207000000_reading_mode.sql`）。画面（99）は下の「画面」にあります。「公開プロフィールなし」で始める入口は、まだ作っていません（99 の2本目）。
- 確かめは `pnpm test:db` の `tests/db-reading-mode.test.ts` です。

## 3つの状態

| 状態                             | 自分の記録・棚・統計                   | 人に届く新しい操作           | 他人から見えるもの                                           |
| -------------------------------- | -------------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| 管理モード                       | できる（新しい物は自分だけ）           | DB が断る                    | 公開プロフィールがあれば、通常モードで見せていた物がそのまま |
| 通常モード・公開プロフィールなし | できる（新しい物は自分だけ）           | 公開プロフィールを作ってから | 何もない                                                     |
| 通常モード・公開プロフィールあり | できる（新しい物は本人のはじめの範囲） | できる                       | 本人が決めた範囲のとおり                                     |

今の読書家は全員「通常モード・公開プロフィールあり」で、何も変わりません。

## モード

- `reader_settings.mode`（`normal`／`manage`）。本人だけが読み書きでき、行がなければ通常。切り替えはこの1列を書くだけで、ほかの行には触りません（何度往復しても、記録・棚・範囲が1つも変わらないことを試験で確かめています）。

## 公開プロフィール

- `profiles.published`。今あるプロフィールは全部 `true`。公開していないプロフィールはユーザーID（`handle`）が空でよく、名前も空でよい。公開するときに ID と名前が要ります（DB の制約）。
- 公開していない人は `private.is_hidden('profile', id)` が真になります。運営が隠した人を外している所（プロフィール、人生の9冊、投稿、記録、一緒に読む、書店、ポスター、本の題名が読めるか、街、検索、人数）は、全部そのまま公開していない人も外します。新しく人を出す所を作るときも、この関数を聞いてください。
- 公開をやめる操作は今はありません（読書家から送られたら断る）。距離を置くのは管理モードと退会です（仮決め、10-24。99 で見直せます）。

## 人に届く操作を断る

`private.reaches_people(人)`（公開プロフィールがあり、通常モード）が偽のとき、読書家からの次の書き込みを DB が断ります。断るときは `42501` で、ヒントが `booktown:reading_mode`（管理モード）か `booktown:no_public_profile`（公開プロフィールなし）です。行の値はエラーに出しません。

- 便り・返信・一緒に読むメモ（ひとりメモは断らない）
- いいね、読みたくなった（押し直しも）、POP への反応
- 人と書店のフォロー、書店へのいいねとひとこと（取り消しは断らない）
- 書店を開くこと、開いている書店の名前・言葉・見た目・公開の棚・店内を変えること（閉店と、閉じている書店の中は断らない）
- ポスターの貼り出しと、貼り出したポスターを直すこと（取り下げ、削除、タイムラインから外す、飾らせない、ネタバレにするは断らない）
- 一緒に読むこと
- 記録・本の読書の状態・ライブラリの棚の範囲を広げること

止めないもの：消す、範囲を狭める、閉店、フォローを外す、ブロックと解除、通報、ネタバレの報告、あとで行く、訪れた書店、一緒に読むを終えること、退会。データベースの仕事（マイグレーション、夜の処理、`give_own_copy`）は断りません。

- 送り直し（`on conflict do nothing`）で、もうある行を送っても断りません。行をまるごと送って上書きする形（書店へのいいねとひとこと）は、変わる中身で決めます。いいねを外してひとことを残す送り方は通ります。
- 一緒に読むは、本・始めた時・人を変えることと、終えたものをまた始めることを断ります。ひとことを別の書店へ付け替えることも断ります。

**仮決め（10-24、99 で見直す）**: 管理モードの間、開いている書店の棚や店内を変える保存は、狭める変更も断ります（閉店すれば変えられる）。貼り出したポスターの中身も直せません。プロフィールの文と人生の9冊を変えること、公開している記録の文を直すことは止めていません。どれも 99 の画面と一緒に決めます。

画面の側（99 で作る）：断られた保存は、ほかのまだ送っていない変更を巻き込まないこと（保存の守り、AUD-002）と、古いタブには上のヒントで「管理モードに切り替わっています」と伝えること。

## 記録したときのモードと、新しい物の範囲

- 本は `library_entries.added_mode`、棚は `library_shelves.made_mode`（どちらも本人しか読めない表の列で、DB が書き、アプリは書けません）。
- 記録と一緒に読むは他人も読む表なので、列にすると管理モードを使ったことが他人に分かります。そこで管理モードで作った物だけを `private.records_made_in_manage`・`private.readings_made_in_manage` に書きます（だれも API から読めない。ない物は通常モード）。
- 管理モードの間と公開プロフィールがない間に作った記録・棚・本の状態は、アプリが何を送っても「自分だけ」で始まります。
- 本の読書の状態（読みたい・読書中・読了）は、本ごとに範囲を持ちます（`library_entries.audience` と `detail`、[公開範囲.md](./公開範囲.md)「見せる範囲」の4つ）。新しい本は本人のはじめの範囲（`status_audience`・`status_detail`）から始まり、はじめの範囲を狭めると今までの本も狭まります（記録と同じ）。

## 人数の数え方

- 決まりは `private.status_counted(本の行)` 1つです。返すのは、ほかの人の数に入る状態と読みたいか、または何も入らない。
  - 管理モードで入れた本は入らない。本人が手で公開にしても入らない（けにーさん 10-18 02:11Z）。
  - 通常モードで入れた本は、範囲が「人数だけ」以上の間だけ入る。「自分だけ」にすればその場で外れる。外した本も入らない。
  - 公開プロフィールのない人と、運営が隠した人は入らない。ブロックでは動かない。
- **外に見せている状態**（けにーさん 10-18 02:16Z）：通常モードで見せていた本を管理モードで変えても、外は通常モードで最後に見せた状態のまま（`status_held`・`shown_status`、`wanted_held`・`shown_wanted_at`）。通常モードでその本の状態か読みたいを次に変えたとき、今の状態がそのまま見えるようになります。管理モードで外した本はその場で外れ、管理モードで戻した本は何も見せません。
  - 本人の本のページに「外ではこう見えています」を出すかは 99 で決めます（この列で読めます）。
- 作品ごとに1人1回：`private.reading_counts(作品の配列)`（読みたい・読書中・読了の人数。同じ作品の版を2冊持つ人は、進んでいるほうで1回）。作品に数えない本（`private.book_counts_in_work`、[本と書誌.md](./本と書誌.md)）は入れず、だれも数に入らない作品は行を返しません（0 を出さないため）。17「みんな」の面などの人数は、これを使う関数から出します。
- `give_own_copy` で本の行を自分の写しへ移すときは、元の行の上の列をそのまま持っていきます。本の行を写す工事を新しく作るときも、上の列を写してください。写さないと、写した行の記録時のモードが今のモードになります。
- 管理モードでも通常モードでも、外した本を戻すと次のとおり。管理モードで戻した本は何も見せず、通常モードで戻した本は今の状態を見せます。
- 書店の先週の訪問の人数（`private.count_shop_visitors`）も、公開プロフィールのない人と運営が隠した人を数えません。

## 規約と13歳以上の確認

- 規約の版は `private.terms_versions`（運営が公開するときに書く、44 で作る。まだ1つもない）。`asks_again` が真の版は、それより前の版にだけ同意した人に聞き直します。
- 同意は `public.terms_consents`（人・版・日時・13歳以上か）。本人だけが読め、今の版にだけ同意でき、直せず消せず、退会で消えます。
- `public.terms_to_agree()` が、今同意してほしい版（なければ null）を返します。

## まだ守っていないこと（作る人が守る）

- `reader_settings` の範囲（本のはじめの範囲 `status_audience` など、ライブラリの棚の範囲 `shelf_audiences`）を広げることは、管理モードでも断りません（はじめの範囲は広げても今までの本に及ばず、新しい本は管理モードの間「自分だけ」で始まる。ライブラリの棚はまだだれにも見せていない）。本棚や統計の数を人に見せる物を作るときは、`private.reaches_people` と `private.is_hidden` を必ず聞いてください。
- フォローといいね・反応の表を読む決まりは、相手が隠れているか（`is_hidden`）を聞いていません。公開をやめる操作がない今は、公開していない人の行はできないので起きません。99 で公開をやめる操作を作るなら、先にここを直します。
- 管理モードで書店を訪れても、店主が見る先週の訪問の人数に入ります（訪れることは断らない物の1つ）。入れないかは 99 で決めます。
- 書店へのいいねを同じ値で送り直すと、更新日時だけ変わります（中身は変わりません）。

## 画面（管理表 99）

けにーさんが 2026-10-25 15:39Z に決めた5つ（仕様7の未決。カード「全部おすすめで進める」）:

1. **最初にモードを選ばせない。** 登録の画面はそのままにし、下に「人とつながらず、自分の記録だけで使う」を1行置く。押した人は名前とIDを決めずに始める（管理モード・公開プロフィールなし）。ふつうの人の手間を1つも増やさない。（2本目で作る）
2. **切り替えは「わたし」の設定のいちばん上**（`ModeSwitch`）。戻すのも同じ所。上や下の帯には置かない。入るときは、変わることを先にその場で見せ（記録はそのまま／新しい物は自分だけで人数に入らない／街と人の物は見えない／今まで見せた物はそのまま見え、閉店や1つずつの非公開はいつでもできる／いつでも戻せる）、押すとホームへ行く。戻すのは1タップ。
3. **管理モードのホーム**（`ManageHome`）は、上から「読んでいる本」（1タップで一人で読み始める・読書中なら戻る）、「本を登録」、「最近入れた本」（木の棚）、「自分の本棚」。下の帯は「書店めぐり」を外した5つ。どれも今ある画面への入口で、自分の行だけを読む。
4. **公開済みの物をまとめて非公開にする操作は作らない**（今は）。2 の説明で、今まで見せた物はそのまま見えることを正直に言う。
5. **SNS を始める手順**: 通常モードで見て回るのは自由。初めて人に届く操作をしたときに名前（とID）を決める小さな画面を出し、決めたらその操作が続く。前の記録は自分だけのまま。（2本目で作る）

- 出さない物: 下の帯の書店めぐり、横の「あなたも、店主に。」、下の街の言葉、検索の読書家・書店・タグの便り・街の一覧（気持ち・話題・多くの棚・棚の隅）、本のページの便り・ポスター・並べている書店・この本との出会い・ほかの人の気持ち・「自分の書店へ」、読書のページの「みんなで読む」・いま読んでいる人・みんなの便り・のぞく・「感想を書く」、わたしの人生の9冊・ポスター・書店・便り・あとで寄る書店・フォローの数、ライブラリと読みたいの「街へ」の入口と店主のPOP。
