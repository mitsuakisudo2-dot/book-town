## 1回の読書

1回の読書は、カード（`reading_cards`）1行と、その中で読んだ本ごとの読書の時間（`reading_sessions`）と、その本の自分だけの側（`reading_card_books`）です。読書カードは、この3つから描きます。

| 表                               | 持つもの                                                                     | 読める人                                                     |
| -------------------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `reading_sessions`（前からある） | 1冊（なしも）を読んだ時間の始めと終わり、一人か一緒に読むか                  | 本人。「一緒に読む」はほかの人にも（いま読んでいる人として） |
| `reading_cards`（新しい）        | 1回の読書。下の「カード」の中身                                              | 本人だけ                                                     |
| `reading_card_books`（新しい）   | カードの本。読書の時間1つにつき1行（読んだ時間、ページ、形式、読み終えたか） | 本人だけ                                                     |
| `reading_notes`（新しい）        | 今日のノート。カードと、書いたときの本を指す                                 | 本人だけ                                                     |

- **自分だけの中身は `reading_sessions` に足しません。** 一緒に読む行はほかの人が読むので、列を足すとその人にも見えるためです（時刻の地域から旅先が分かる、どの行が同じ読書かが分かる、など）。読書の時間からカードは指さず、カードの本から読書の時間を指します。なお一緒に読んでいる人が本を変えると、前の本の終わりと次の本の始めが同じ時刻になり、同じ読書だとほかの人にも推し量れます。いま読んでいる本が変わったことはもともと見えているので、これで新しく分かることはありません。
- **読書を始めるとき**、アプリは読書の時間、カード、カードの本を作ります（この順）。
- **本を変えたとき**: 読み始めて1分未満なら、今の読書の時間の本を変えるだけです（前の本は残らない）。1分以上なら、今の読書の時間を終えてから（動いている読書の時間は1人に1つだけで、終える前に次を入れると `23505` で断られます）、新しい本の読書の時間を始めて、同じカードの本に足します。時計（一時停止・タイマー）はカードが持つので、そのまま続きます。
- **この工事より前の読書の時間**にはカードがありません（カードの本の行がない）。アプリはそれを1冊だけのカードとして、読書の時間にある物（本と時刻）で、どの選択もはじめの値で見せます。今ある行を書き換えたり移したりはしていません。
- **記録しない**（「記録しないで閉じる」を2回押したとき）: アプリはカードの読書の時間を全部消してから、カードを消します。読書の時間を消すとカードの本が消え、カードを消すと残りの本とノートが消えます（外部キーの連鎖）。カードの本だけを消す権限はありません。順を逆にすると、残った読書の時間が「前からある読書の時間」に見えるので、この順を守ります。
- **読書にもどる**（「おわり」のあと）: 同じカードで続けます（最後の読書の時間の終わりを空に戻す。一緒に読むときは、人に届く操作として管理モードの決まりがかかります）。

## カード（`reading_cards`）

鍵は `(user_id, id)` で、ID は端末が作ります。ほかの人が先に同じ ID を使っても、その人の行にはなりません（送り直しが何も書かずに「保存した」に見えないため）。

| 列                                                   | 中身                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time_zone`                                          | 読んだときの端末の地域（`Intl` の名前か、`+09:00` の形の時差）。カードの日付・曜日・季節・朝昼夜はここから出します。形だけを確かめ、この DB が知らない名前も残します（読むときは日本として扱う）。空やほかの形は、断らずに日本（`Asia/Tokyo`）にします。はじめは `Asia/Tokyo` |
| `added_later`                                        | 「記録し忘れた日を、あとから足す」で足した読書。時刻は時計ではなく本人が選んだもの                                                                                                                                                                                            |
| `paused_at`・`paused_seconds`                        | 一時停止の間はいつからか、それまでの一時停止の合計の秒                                                                                                                                                                                                                        |
| `timer`・`timer_minutes`・`rest_minutes`・`timer_at` | 決めない（`none`）・タイマー・ポモドーロ、決めた分（ポモドーロは読む分）と休む分、今の使い方が始まった時刻（途中で変えたら、そこから数え直す）                                                                                                                                |
| `room`・`light`                                      | 読んだ部屋の見た目と光の気分                                                                                                                                                                                                                                                  |
| `look`                                               | カードの見た目                                                                                                                                                                                                                                                                |
| `shown`                                              | このカードに何をどう載せるか（どの項目か、ページの順、指で動かした配置）。形はアプリが決め、DB は 65536 バイト（ポスターの半分）までのオブジェクトであることだけを確かめます。大きさは DB が書く形（`jsonb` の文字。`JSON.stringify` より空白が多い）で測ります               |

- `room`・`light`・`look` は、アプリの名前（英小文字・数字・`-`、40字まで）の形だけを確かめます。あとで足した見た目も断られず、アプリにもうない見た目は、そのはじめの見た目で描きます。
- 範囲（タイマー 1〜300分、ポモドーロの読む 1〜120分、休む 1〜30分）はアプリが守り、DB は1日分（1〜1440分）までを確かめます。DB が断ると送り待ちの書き込みが全部止まるので、DB は正しいアプリが送らないものだけを断ります。
- 端末の時計が進んでいても、`created_at` は今より先になりません。`paused_at`・`timer_at` は、読書の時間の始めと終わりと同じく端末の時刻のままにします（端末の時計どうしで引き算が合うように）。
- **時刻の地域を SQL で読むとき**: `at time zone` は、知らない名前（`Etc/Unknown` など）で失敗し、`+09:00` を西に9時間と読みます（ISO と逆）。統計の工事では、`at time zone` で失敗する物（知らない名前、`+99:99` のようなありえない時差）はどれも日本にし、時差は符号を逆にしてから使います。

## カードの本（`reading_card_books`）

鍵は `(user_id, session_id)` で、`reading_sessions (user_id, id)` と、カード `(user_id, card_id)` を指します。読書の時間は1枚のカードにだけ入ります。自分の読書の時間しか指せず、ほかの人の行を指すと、その行がカードに入っていてもいなくても、行がなくても同じ `23503` で断られます（ほかの人の一緒に読む行が読書カードにあるかを聞く手段にしないため）。

| 列                                  | 中身                                                                                                                                                                                                                                                                                    |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `read_seconds`                      | この本を読んだ時間（アプリがこの本の読書の時間を終えたときに数えた秒。一時停止と休みを除く）。読んでいる間と、アプリが数えられなかったときは空で、そのときは終わり − 始め。何か月も止め忘れた読書もそのまま残します（統計で1回の長さをどう扱うかは統計の工事で決める）。負は 0 にします |
| `page_from`・`page_to`・`page_unit` | 何ページから、どこまで読んだかと、その単位: ページ（`page`、はじめ）・電子書籍の％（`percent`）や位置（`location`）・音声の秒（`second`）。画面でどれを選べるかはまだ決まっていません（音声は時間、電子は％も、は Claude の案で未回答）。本のページ数で数えるのは `page` だけ           |
| `format`                            | 紙（`paper`）・電子（`ebook`）・音声（`audio`）。空は「言っていない」                                                                                                                                                                                                                   |
| `finished`                          | この読書で「この本を読み終えた」。再読のたびに1回ずつ残ります。本の状態（読了）はライブラリが持ちます                                                                                                                                                                                   |

- カードの読んだ時間はカードの本の合計、始めと終わりはその読書の時間の最初と最後、本の並びは読書の時間の始めの順です（持たずに出す）。
- 一時停止は合計の秒だけを持ち、いつ止めたかは持ちません。夜中の0時をまたいだ読書を日ごとに分けた時間は、近い値になります。

## 今日のノート（`reading_notes`）

- 言葉を調べる（`word`、調べた言葉そのもの）・思ったこと（`thought`）・好きな一文（`quote`）。本文は2000字まで、空白だけ（全角の空白も）は入りません。書いたページ（`page`）は言ったときだけで、書いたときの本のページです。
- カード（`card_id`）と、書いたときの本（`session_id`、同じカードの本だけ）を指します。本のない読書のときは本が空です。本がカードから消えても（読書の時間を消したとき）、ノートはカードに残り、本が空になります。本が消えたあとに別の端末から届いたノートも、どのカードにもない本を指したノートも、DB が本を空にしてカードに残します（送り待ちの箱を止めず、書いた言葉を失わないため）。同じ人のほかのカードの本を指したときだけ `23503` で断られます（正しいアプリは送らない）。
- ID は端末が作ります（同じ物を送り直しても1行）。鍵は `(user_id, id)` で、カードと同じくほかの人の ID は取れません。種類・本文・ページは直せて、1つずつ消せます。
- 「思ったことを本のページに出す」は、選んだときにアプリが投稿（`posts`）を作ります。ノートそのものはずっと自分だけです。

## アプリが書くときの決まり

- 書く順は、読書の時間 → カード → カードの本 → ノート。本を変えるときは、前の読書の時間を終える `update` を、次の読書の時間より前に置きます。送り待ちの箱でもこの順に並べます。「記録しない」（読書の時間を消してからカードを消す）は、読書の書き込みのいちばん先に送ります。記録しないですぐ次の読書を始めて、まとめて送られたときに、残った読書の時間が「動いているのは1人に1つ」で次を断らせないためです。
- アプリが読書の時間を消すのは「記録しない」のカードの読書の時間だけです（街から消えた読書の時間でも、カードのないものは消しません）。
- カード・カードの本・ノートは「あれば何もしない」で入れ（`insert … on conflict do nothing`、supabase-js では `upsert` の `ignoreDuplicates`）、変わった所は `update` で送ります。重なりを見る鍵は、カードとノートが `onConflict: "user_id,id"`、カードの本が `onConflict: "user_id,session_id"` です（書かなくても同じ）。ほかの表の `onConflict: "id"` をまねると、`id` だけの鍵はないので `42P10` で断られます。ふつうの `upsert`（重なったら書き換え）は鍵の列も書き換えようとして `42501` で断られます。
- まとめて送る行は、どの行も同じ列をそろえます。supabase-js は、ほかの行にあってその行にない列を空（null）で送ります。はじめの値がある列（`timer`、`added_later`、`shown`、`time_zone`、`paused_seconds`、`page_unit`、`finished`、`created_at`）は、空で届いても DB がはじめの値にしますが、ほかの列は空のまま入ります。
- 別の端末で「記録しない」を選んでカードが消えたあとに届いたカードの本やノートは `23503` で断られます。ほかの断られた保存と同じく、その1件だけを除いて残りを送り、「保存できなかった」と知らせます（`src/lib/supabase/sync.ts`）。出会いの記録のように黙って捨てないのは、ノートには読書家の言葉が入っているからです。その前に入った読書の時間（本を変えたときの次の本など）は消しません。カードの入れ方が別の理由で断られたときも同じ `23503` になり、保存できた読書の時間を消すと時間が失われるためです。残った読書の時間は、カードのない「前からある読書の時間」として数えます。
- 本を外す操作では、最後の1冊は外せません（外すなら「記録しない」）。なので本のないカードは「記録しない」が途中で止まった物で、ノートが残っていてもアルバムに出しません。

## アプリの時計

- 読んでいる本の時間は「カードの最初の本を読み始めてから今まで − 一時停止の合計（止めている間はその分も）− カードのほかの本の時間」です。本を変えても時計は続き、本ごとの時間はその本の読書の時間を終えたときに `read_seconds` に残します。止めたまま終えたときと、止めたまま本を変えたときは、止めた分を合計に入れて止めるのをやめます（本を選んだら、その本を読んでいる）。
- 「読書にもどる」は、カードの最後の読書の時間の終わりを空に戻し、終えてから戻るまでを一時停止の合計に足します（その本の `read_seconds` は空に戻し、次に終えたときに数え直す）。戻れるのは、いちばん最後に始めた読書のカードだけです（あとに別の読書があると、日と順が実際と食い違うため）。
- 読み始めて1分未満で本を変えたときは、その本のライブラリの「読書中」（とその間に付けた「読了」）を、このページで付けたものなら前の状態に戻します。その本で今日のノートを書いていたら入れ替えず、1分以上のときと同じく前の本もカードに残します（ノートはその本のもの）。「この本を読み終えた」の「読了」は外したときに、読書で付けた「読書中」と「読了」は「記録しない」のときに、このページで付けたものなら戻します（記録しないは、その読書がなかったことにする）。ページを開き直したあとは戻しません（ライブラリは本人が直せる）。
- 「記録し忘れた日を、あとから足す」と、このアプリで読まなかった読書（けにーさん 10-27「このアプリで読まなくても読書を記録できるように」）は、同じ1つの操作（`addReadingLater`）で、終わった読書の時間1つとカード1枚（`added_later`）にします。始めた日時は本人が選び（今より先は受けない）、読んだ時間は1秒から1日まで、わからなければ空にして始めと終わりを同じにし、カードの本の `read_seconds` を 0 にします（読んだ時間の合計には足さず、ページだけが残る）。ひとりで読んだものとして入れ、一緒に読むの一覧には出ません。あとから足したカードは「読書にもどる」で続けられません。「読み終えた」を選べば、ライブラリを読了にします（「記録しない」と外したときは戻す）。DB は #390 の形のままで受けます。
- 基本の読書時間（`readingTotals`）は、カードのある読書の時間では一時停止を除いた時間を数えます。カードのない前からの読書の時間は、終わり − 始めのままです。
- 街を読むとき、自分のカード・カードの本・ノートを1つずつ頼みます（3つ増えた。ほかの自分だけの表と同じく並べて頼む）。ノートは何年分もたまると重くなるので、統計やアルバムを作るときに、読む範囲をしぼるかを決めます。

## 読書中の画面

コードは `src/components/ReadingRoom.tsx`（読書中）、`ReadingDone.tsx`（「おわり」のあと）、`ReadingTogether.tsx`（いま読んでいる人と便り）、見た目は `reading-room.css` です。読書のページ（`ReadingView.tsx`）は、読書が動いていれば読書中の画面、「おわり」のあとはカード、ほかは読書を始める画面を出します。

- 読書中の画面は、街の上の帯と下の帯の上に画面いっぱいに重ねます（重なりは `--layer-page`。小窓と知らせはその上）。知らせは上の印の下に出します（下の書く欄を隠さないため）。
- 上: ⌄（ホームへ。読書は続く）、人の印、電球（画面をつけたままにする。Wake Lock。端末が対応しないときはそう知らせ、ページを開き直すと頼み直す）。人の印は、みんなで読むときは「いま読んでいる人」と便りを書く所、一人で読むときは街の読書をのぞくだけ（自分は人数に入らず、書く所はない）。読書管理モードでは出しません。前の「読書中はいつも開いておく」の設定（わたし）は、この印に置き換えてなくしました。
- 真ん中: 本（表紙を押すと大きく見る、題名を押すと本を変える。何ページからか、表紙の出どころ）と、光の輪の時計です。時計は 0:00 から数え、1時間を過ぎると 1:00:00 の形にし、光は1時間で1周します。止めると「ひと休み中」になり、続きから読めます。
- 下: 書く欄の3つの切り替え（はじめは思ったこと）と「残す」（Enter でも）、「おわり」、ノート。ノートは横に送ると今日のノート（自分だけ）で、消すときは1回聞きます。
- **書く欄の書きかけ**は、カードごと・持ち主ごとにこのブラウザに残し（`src/lib/reading-note-draft.ts`、`book-town-reading-note-drafts-v1`）、ノートに入るか本人が消すまで消しません。開き直したときは「書きかけを続けています」と消す所を出します（`KeptDraftNote`）。「おわり」は書きかけをノートに入れてから終え、入らなかったときは「おわり」のあとと読書のページ（「ノートに残していない言葉」）に残します。DB に断られたノートの言葉は、そのカードの書きかけの後ろに戻ります（`src/lib/missed-changes.ts`）。
- **便り**（みんなで読むとき）の書きかけは今までどおり読書の時間ごとで、送らずに終えると読書のページの「読みながら書いて、送っていない言葉」に残り、感想に使えます。
- **「おわり」のあと**（カードができました）: 本ごとの「どこまで読んだ？」（ページ）と「この本を読み終えた」（ライブラリの読了も付け外し）、感想を書く（本のあるときだけ。読書管理モードでは出さない）、カードをしまう、記録しないで閉じる（2回押す）、読書にもどる。「おわり」に確かめの小窓は出しません（読書にもどるで戻れるため）。
- **まだのこと**（どれも上の決定の中で、あとの工事）: 「アルバムにしまう」はアルバム（3本目）までは「カードをしまう」で、カードの見た目も3本目。「言葉を調べる」は辞書（5本目）までは言葉を残すだけ。タイマーとポモドーロ、部屋と光。「思ったことを本のページに出す」（今は感想を書くから）。ノートを直す画面（操作 `changeReadingNote` はある）。ほかのページの下の「読書中」の帯（今は下の帯の「読書中」で戻れる）。読み終わりまでの見込みの時間は出しません（本のページ数を持っていないため）。

## 出して数えるもの（持たないもの）

次は持たず、ほかの行から出します。持たない物は、あとで決め方を変えても作り直しが要りません。

- カードの日付・曜日・季節・朝昼夜（読書の時間の時刻と `time_zone` から）。
- カードの始めと終わり、読んだ時間（カードの本と読書の時間から）。
- 本と「この本で何回目か」（その本が入ったカードの数。1回の読書で同じ本に戻っても1回）。
- 次に読むときの部屋・光・カードの見た目・形式（いちばん新しいカードとその本から）。
- 基本の統計（管理表 19）: 読んだ時間と日は読書の時間とカードの本から、読み終えた本と再読は `finished` とライブラリの読了から、ページは `page_to`（単位が `page` のもの）と書誌のページ数から、気持ちは `reading_entries` から。星（自分だけ）と、分類を本人が直す・足す所は、統計の工事で足します（まだ置き場がありません）。

## 基本の統計の数え方（管理表 19、2026-10-28〜）

β前に入れる統計は、けにーさんが 10-28 に決めた12枚です（見本と札ごとの中身はリポジトリの外の「統計_工事向けのまとめ_刷新版_2026-10-28.md」）。数え方は `src/lib/reading-stats/` の純粋な関数で、確かめは `tests/reading-stats.test.ts`（`pnpm test:domain`）です。画面は記録の画面の「読書をはじめる」の下にあります（`src/components/stats/`、別ファイルで後から読む）。

- **決まっている4つ**（けにーさん 10-27「そろそろ計算方法を統一して」）: 平均は合計 ÷ 日数（期間のはじめか記録のはじめの遅いほうから今日まで。`elapsedDays`）。ペースは選んだ期間の速さ、なければこの1年、なければこれまで（`readingSpeed`。時間とページの両方がある読書だけで数える）。読み終えるまではその本の速さ、なければその速さ（`timeToFinish`）。かかった時間は切り捨て、見込みだけ「約」で四捨五入（関数は丸めず、画面が丸める）。
- **時刻**: 日・時・曜日は、その読書のカードの `time_zone` の時計で読みます（`localTime`。`+09:00` は東へ9時間。知らない名前は日本）。期間は読む人の端末の時計の日で決めます。
- **決まり（10-28 けにーさん「それで」）**: 1回の読書は12時間まで数え、始めから12時間の所に置く（`READ_SECONDS_MAX`。止め忘れたあとの日は読んだ日にならない。カードはそのまま）。日や時をまたいだ読書は時刻の長さで分ける（`piecesOf`）。読んだページは「どこまで」−「どこから」（なければその本の前の読書の「どこまで」）、単位がページの物だけで、音声は数えない。ページを書かずに読み終えた本は、書誌のページ数の残りを読み終えた日に足す（読んだページには入るが、ペースには書いたページだけを使う）。読み終えたのはカードの「この本を読み終えた」で、再読も1冊。ページ数の分からない本は冊数に入れ、ページ・厚さから外す。
- **決定（けにーさん 10-28 カード「「ぜんぶ」だけに入れる」）**: カードがなくライブラリだけが読了の本は読了にした時刻で数え、登録と同時（1分以内）に読了にした本は、いつ読んだか分からないので日付なしで「ぜんぶ」と本棚の状態だけに入れる（`REGISTERED_FINISHED_MS`）。
- **書誌が要る物**: ページ数と大きなジャンル（16種）は `public.book_facts(ids)` で読みます（書誌と同じ条件で見せる本だけ。ジャンルは運営が決めた作品のジャンル、なければその版の NDC から。マイグレーション `book_facts`、確かめは `tests/db-book-facts.test.ts`）。関数は本ごとの `BookFacts` を受け取ります。ジャンルの分からない本は「そのほか」に入れます。
- **札の並び（けにーさん 10-28 11:36Z「おすすめ」）**: 札の順・大きさ（2×2 `half`、2×4 `wide`、最大 `full`）・空き（＋）はアカウントに残します（`reader_settings.stats_layout`、空なら最初の並び `FIRST_LAYOUT`）。DB は「64か所・4096バイトまでの配列」だけを確かめ、中身はアプリが読みます（知らない札は外す。新しいアプリの並びで古いアプリが壊れない）。動かす・大きさ・外す・＋の決まりは `src/lib/reading-stats/layout.ts`、確かめは `tests/stats-layout.test.ts`。読んだ日の札は、画面の期間にかかわらず「今月」を出します（同じ決定）。
- **並べ替えの手（刷新版 3節）**: 札を長押し（0.48秒、並べ替え中は0.26秒）で持ち上がり、全部の札が揺れて左上に − が付きます。運ぶと、指が下の札の真ん中を越えたときだけ `move` で入れ替わり、離したときに1回だけ保存します。下の窓は選んだ札の大きさ3つと［完了］、外した直後だけ「元に戻す」。札の外を押すか Esc で終わります。手は `StatsBoard.tsx`、決まりは `layout.ts` だけにあります。2×2 と 2×4 の札は押すと下から窓が開き、下に引いても閉じます（`useSheetPull.ts`）。長押しを知らない人のために、期間の帯の下に［並べ替え］も置きます（押すと同じ並べ替えの状態になる）。札の下には置きません（試作 v28「足すより見せ方」、同じ操作を2か所に置かない）。

- **試作と同じにする（けにーさん 10-28 14:06Z「試作と同じようにしてくれるならOK」）**: 試作と本番の違いの一覧はリポジトリの外の「試作と本番の違い_2026-10-28.md」。部屋（着せ替え）の工事までは、いつもの色と字のまま形だけそろえます（仮決め）。札の頭と今年の読書の4つの数には、色の丸の中に試作の印（`charts.tsx` の `Mark`）。4つの数は札の中の幅が 320px あれば横1列、なければ 2×2（字は 12px より小さくしないので、横1列のとき「読んだページ」の数は単位を外す）。今年の読書の棚は、左に読書中の本を重ねて立て、しおりの高さで読んだところまで、読み終えた本は月ごとに板で分けて札に月の名前（期間が年とぜんぶのとき）。読書時間チャートは目盛りと罫線、平均の点線、いちばん長い棒と今の棒の数、押した棒は上の右に「4月 16時間19分」（`TimeChart`）。

## 守ること

- 読書家のデータを失わせない。今ある `reading_sessions` と `reading_entries` の行は、この工事で1行も書き換えていません。
- 人と比べない。カードとノートはほかの人に見えず、人数にも数えません。読書管理モードの人も、公開プロフィールのない人も、同じに書けます（人に届かないため）。
- 書き込みの数の上限は、ほかの自分だけの表と同じく、まだありません（AUD-021・AUD-127 で共通の形にする）。1行の大きさには上限があります。
- 退会すると、カードもカードの本もノートも消えます（`tests/fixtures/account-tables.ts`）。
