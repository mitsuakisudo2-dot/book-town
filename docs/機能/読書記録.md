# 読書記録

読書記録（管理表 18）と、その基本の統計（管理表 19）の、データの決まりの正本です。何を作るかの相談のまとめと画面の見た目は、リポジトリの外の資料にあります（Claude Doc「読書記録の相談のまとめ」の2節の最後「最初の工事で作る物」と「読書記録の見た目（開発に渡す決まり）」）。ここには、今のコードと DB がどう持っているかを書きます。だれが何を読めるかの全体は [公開範囲.md](./公開範囲.md)、DB の工事の書き方は [DBの変え方.md](../開発と運用/DBの変え方.md) にあります。

- 最初の工事は何本かに分けて出します。1本目はデータの形（`supabase/migrations/20261211000000_reading_cards.sql`）で、画面はまだこの表を読み書きしません。
- 確かめは `pnpm test:db` の `tests/db-reading-cards.test.ts` です。

## 決まっていること・まだのこと（2026-10-26）

- **決定**: 読書中の画面と時計（光の輪、タイマーとポモドーロ、時間の決め方、一時停止、本を変える、書く欄の3つの切り替え、「おわり」のあと）。
- **未決定**: カード・着せ替え・アルバム・カレンダー・統計の見た目（試作の窓・手帳・入場券は案のまま。けにーさん 10-26「まだ決まってないよね？」）。データの形は、見た目がどう決まっても作り直さないように、見た目の名前と見せ方を中身から分けて持っています（下の「カード」）。

## 1回の読書

1回の読書は、`reading_sessions` の1行（読書の時間）と、その行の自分だけの側 `reading_cards` の1行です。読書カードは、この2つから描きます（1回の読書で1枚、けにーさん 10-25 02:38「B」）。

| 表                               | 持つもの                                                  | 読める人                                                     |
| -------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------ |
| `reading_sessions`（前からある） | 本（1冊、なしも）、始めと終わりの時刻、一人か一緒に読むか | 本人。「一緒に読む」はほかの人にも（いま読んでいる人として） |
| `reading_cards`（新しい）        | 下の「カード」の中身。読書の時間1つにつき1行              | 本人だけ                                                     |
| `reading_notes`（新しい）        | 今日のノート                                              | 本人だけ                                                     |

- **自分だけの中身は `reading_sessions` に足しません。** 一緒に読む行はほかの人が読むので、列を足すとその人にも見えるためです（時刻の地域から旅先が分かる、など）。
- **アプリが読書を始めるときに、`reading_sessions` の行とカードの行を作ります**（カードは読書の時間の行のあと）。この工事より前の読書の時間にはカードがありません。アプリはそれを、読書の時間にある物（本と時刻）だけのカードとして、どの選択もはじめの値で見せます。今ある行を書き換えたり移したりはしていません。
- **本を変えたとき**（10-26 の見た目の決まり）: 読み始めて1分未満なら同じ読書の時間の本を変えます。1分以上なら、それまでの分をカードにして終え、新しい本で新しい読書の時間とカードを始めます。どちらも1回の読書は1冊です。あとで「1枚のカードに何冊も」が要るときは、カードに「どのカードの続きか」を足してつなぎます（今の行は作り直しません）。
- **記録しない**（「記録しないで閉じる」を2回押したとき）: アプリが読書の時間の行を消し、カードと今日のノートも一緒に消えます（外部キーの連鎖）。カードだけを消す権限はありません。
- **読書にもどる**（「おわり」のあと）: 同じ読書の時間を続けます（終わりの時刻を空に戻す。一緒に読むときは、人に届く操作として管理モードの決まりがかかります）。

## カード（`reading_cards`）

鍵は `(user_id, session_id)` で、`reading_sessions (user_id, id)` を指します。自分の読書の時間しか指せず、ほかの人の行を指すと、その行があってもなくても同じ `23503` で断られます（ほかの人の一緒に読む行にカードがあるかを聞く手段にしないため）。

| 列                                                   | 中身                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `time_zone`                                          | 読んだときの端末の地域（`Intl` の名前か、`+09:00` の形の時差）。カードの日付・曜日・季節・朝昼夜はここから出します。形だけを確かめ、この DB が知らない名前も残します（読むときは日本として扱う）。空やほかの形は、断らずに日本（`Asia/Tokyo`）にします。はじめは `Asia/Tokyo` |
| `added_later`                                        | 「記録し忘れた日を、あとから足す」で足した読書。時刻は時計ではなく本人が選んだもの                                                                                                                                                                                            |
| `paused_at`・`paused_seconds`                        | 一時停止の間はいつからか、それまでの一時停止の合計の秒                                                                                                                                                                                                                        |
| `timer`・`timer_minutes`・`rest_minutes`・`timer_at` | 決めない（`none`）・タイマー・ポモドーロ、決めた分（ポモドーロは読む分）と休む分、今の使い方が始まった時刻（途中で変えたら、そこから数え直す）                                                                                                                                |
| `read_seconds`                                       | 読んだ時間（アプリが「おわり」で数えた秒。一時停止と休みを除く）。読書中と、この工事より前の読書の時間は空で、そのときは終わり − 始め − `paused_seconds`。何か月も止め忘れた読書もそのまま残します（統計で1回の長さをどう扱うかは統計の工事で決める）                         |
| `page_from`・`page_to`・`page_unit`                  | 何ページから、どこまで読んだかと、その単位: ページ（`page`、はじめ）・電子書籍の％（`percent`）や位置（`location`）・音声の秒（`second`）。画面でどれを選べるかはまだ決まっていません（音声は時間、電子は％も、は Claude の案で未回答）。本のページ数で数えるのは `page` だけ |
| `format`                                             | 紙（`paper`）・電子（`ebook`）・音声（`audio`）。空は「言っていない」                                                                                                                                                                                                         |
| `finished`                                           | この読書で「この本を読み終えた」。再読のたびに1回ずつ残ります。本の状態（読了）はライブラリが持ちます                                                                                                                                                                         |
| `room`・`light`                                      | 読んだ部屋の見た目と光の気分                                                                                                                                                                                                                                                  |
| `look`                                               | カードの見た目                                                                                                                                                                                                                                                                |
| `shown`                                              | このカードに何をどう載せるか（どの項目か、ページの順、指で動かした配置）。形はアプリが決め、DB は 65536 バイト（ポスターの半分）までのオブジェクトであることだけを確かめます。大きさは DB が書く形（`jsonb` の文字。`JSON.stringify` より空白が多い）で測ります               |

- `room`・`light`・`look` は、アプリの名前（英小文字・数字・`-`、40字まで）の形だけを確かめます。あとで足した見た目も断られず、アプリにもうない見た目は、そのはじめの見た目で描きます。
- 範囲（タイマー 1〜300分、ポモドーロの読む 1〜120分、休む 1〜30分）はアプリが守り、DB は1日分（1〜1440分）までを確かめます。DB が断ると送り待ちの書き込みが全部止まるので、DB は正しいアプリが送らないものだけを断ります。
- 端末の時計が進んでいても、`created_at` は今より先になりません。`paused_at`・`timer_at` は、読書の時間の始めと終わりと同じく端末の時刻のままにします（端末の時計どうしで引き算が合うように）。
- 端末の時計で引き算が負になった秒（`read_seconds`・`paused_seconds`）は、断らずに 0 にします。
- **時刻の地域を SQL で読むとき**: `at time zone` は、知らない名前（`Etc/Unknown` など）で失敗し、`+09:00` を西に9時間と読みます（ISO と逆）。統計の工事では、知らない名前を日本にし、時差は符号を逆にしてから使います。

## 今日のノート（`reading_notes`）

- 言葉を調べる（`word`、調べた言葉そのもの）・思ったこと（`thought`）・好きな一文（`quote`）。本文は2000字まで、空白だけ（全角の空白も）は入りません。書いたページ（`page`）は言ったときだけ。
- カードを指します（`(user_id, session_id)`）。カードのない読書の時間には書けないので、アプリは先にカードを作ります。
- ID は端末が作ります（同じ物を送り直しても1行）。鍵は `(user_id, id)` で、ほかの人が先に同じ ID を使っても、その人の行にはなりません（送り直しが何も書かずに「保存した」に見えないため）。種類・本文・ページは直せて、1つずつ消せます。
- 「思ったことを本のページに出す」は、選んだときにアプリが投稿（`posts`）を作ります。ノートそのものはずっと自分だけです。

## アプリが書くときの決まり（2本目の工事から）

- 書く順は、読書の時間 → カード → ノート。送り待ちの箱でもこの順に並べます。
- カードは「あれば何もしない」で入れ（`insert … on conflict do nothing`、supabase-js では `upsert` の `ignoreDuplicates`）、変わった所は `update` で送ります。ふつうの `upsert`（重なったら書き換え）は `user_id`・`session_id` も書き換えようとして `42501` で断られます。
- ノートを書く前に、カードを「あれば何もしない」で入れます。前のアプリや別の端末で始めた読書の時間には、カードがないことがあるためです。
- 別の端末で「記録しない」を選んで読書の時間が消えたあとに届いたカードやノートは `23503` で断られます。出会いの記録（`book_encounters`、`src/lib/supabase/town-backend.ts`）と同じく、その1件を捨てて次へ進みます（送り待ちの箱を止めない）。

## 出して数えるもの（持たないもの）

次は持たず、ほかの行から出します。持たない物は、あとで決め方を変えても作り直しが要りません。

- カードの日付・曜日・季節・朝昼夜（時刻と `time_zone` から）。
- 本と「この本で何回目か」（読書の時間から）。
- 次に読むときの部屋・光・カードの見た目・形式（いちばん新しいカードから）。
- 基本の統計（管理表 19）: 読んだ時間と日は読書の時間とカードから、読み終えた本と再読は `finished` とライブラリの読了から、ページは `page_to`（単位が `page` のもの）と書誌のページ数から、気持ちは `reading_entries` から。星（自分だけ）と、分類を本人が直す・足す所は、統計の工事で足します（まだ置き場がありません）。

| 足すもの                           | 置く所                                                          |
| ---------------------------------- | --------------------------------------------------------------- |
| 自分で作る項目と、その答え         | 項目の表と、カードを指す答えの表を足す                          |

| 一緒に読んだ人、誰もいなかったこと | カードを指す表を足す                                            |
| メモモード（管理表 36）            | 本ごとのメモの表を別に足す                                      |

## 守ること

- 読書家のデータを失わせない。今ある `reading_sessions` と `reading_entries` の行は、この工事で1行も書き換えていません。
- 人と比べない。カードとノートはほかの人に見えず、人数にも数えません。読書管理モードの人も、公開プロフィールのない人も、同じに書けます（人に届かないため）。
- 書き込みの数の上限は、ほかの自分だけの表と同じく、まだありません（AUD-021・AUD-127 で共通の形にする）。1行の大きさには上限があります。
- 退会すると、カードもノートも消えます（`tests/fixtures/account-tables.ts`）。
