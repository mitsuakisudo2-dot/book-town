# 連続登録

本のバーコードを続けて読み、読んだそばからマイライブラリに登録する仕組み（連続スキャン、スキャナー）の正本です。ライブラリの表と状態の決まりは [本棚とライブラリ.md](./本棚とライブラリ.md)、本の行と書誌は [本と書誌.md](./本と書誌.md)、送り待ちの箱とログアウトは [docs/09](../09_段階2_ログインと保存.md)「その3で決めたこと（保存先の切り替え）」、`barcode-detector` と `zxing-wasm` の版の決まりは [CLAUDE.md](../../CLAUDE.md)「ファイル」にあります。docs/09 から移した節です（2026-10-23）。

## 端末の控えと登録

- **連続スキャンの控えは、その端末にだけ置く**（localStorage、アカウントごと、`src/lib/library-journal.ts`）。本のIDは読み取った時点で決めて控えに書くので、送り直しても、2つのタブから送っても、本は1冊になる。書名と著者は本と同じく200字で切ってから控えに書き、価格は範囲の外なら書かない（読み返すときも同じにするので、1つの値のせいで読んだ本が控えから消えることはない）。保存されたら消え、7日で消え、ログアウトを押すと消える（トークンの更新に失敗したときは消さない）。書名がわからない本はデータベースに書かず、控えにだけ置き、プロフィールの「登録」タブに「書名待ち」として出す。データベースに断られた本は自動で送り直さず、「送れなかった本」として出す。2台の端末で同じ ISBN を、どちらも読み込み直す前に読むと、ライブラリに2冊並ぶ（自分が作った行を見分けるにはデータベースの変更がいるので、あとの作業にする）。スキャナーの一覧（新しい本が上、Figma v4 の 01）は、控えから消えた本、つまり保存が確かめられた本だけを「登録しました」と言い、上の「N冊 登録済み」に数える。それまでは「保存しています…」で「確認中」に、この端末に保存できないときは「端末に控えました。ページを読み込み直すと登録します」で「要確認」に数える。連続設定（読書状況・持っている・本棚、資料3章）は、読んだ本と一緒に控えに書き（`ScanSort`）、その本が新しくライブラリに入ったときにだけ付ける。もうライブラリにある本は変えない。持っているは最初からオン（けにーさん 2026-10-18）。完了で消え、次に開いたときは付いていない。「持っている」はスキャナーの連続設定の段の左にもスイッチで出て（2026-10-19 けにーさんの注釈）、連続設定の中のスイッチと同じもの。最初からオンで、連続設定をしていなくても、新しく入る本は「持っている」で入り、オフにすると「未所持」で入る（けにーさん 2026-10-19 のカード「最初からオン」。連続登録では「登録では所有を書かない」をこれで変えた）。解除しても、スイッチはそのまま。段の右は［連続設定］で、連続設定中は［変更］［解除］と、その下に付けるもの（読書状況と本棚）を出す。スキャンで新しく入った本の行には、その回の id（UUID）を `batch_id` に書く（前からある「今回追加」の欄、スキャナーの中で手で入れた本も同じ）。完了を押さずに閉じた回（✕・戻る・ページを閉じた）は、次にスキャナーを開いたときに「前回の登録を続けますか？」と1度聞き、続きから再開でその回の本を一覧に戻して数え続ける（Figma v4 の 09）。今はしない・完了でその回は聞かなくなる。この端末に残すのは回の id と時刻と連続設定だけで、7日で消え、退会で消える（`src/lib/scan-resume.ts`）。再開を聞く小窓には前回の連続設定を出し、［連続設定も戻す］を押したときだけ戻す（押さなければ付けずに続ける。気づかないまま次の本を分けないため、資料3章。もうない本棚は戻さない）。コンパクト表示（資料4章、けにーさん 2026-10-18 のカード「題名と3つ」）は、下のバーの左端で切り替え、ライブラリに入った本を1行（表紙・題名・読了・積読・読書中）にする。確認が要る本はいつもの形のまま。切り替えはこの端末に残す（`book-town-scan-compact`）。本ごとの下の段のボタン（自由3枠、資料4章）は、はじめは未所持・お気に入り・＋本棚で、下のバーの［下の段のボタンを選ぶ］から、未所持・お気に入り・＋本棚・手で並べる本棚の1つ、のうち3つまでを選んで左右に並べ替える（けにーさん 2026-10-19「自由設定は良い」、入口はカードで「下のバー」）。「並び」は本の下の段と同じ横並びで出し（2026-10-19 けにーさんの注釈）、ボタンを指（マウスでも）でつかんで横へ動かして並べ替える（2026-10-19 けにーさん「並びはドラッグ&ドロップで変えられるように」）。キーボードではスペースでつかみ、左右の矢印で動かし、スペースで置く。動かしている間の読み上げは小窓の中に出す。外すのは下の「並べられるもの」で。この端末に残し（`book-town-scan-slots`、`src/lib/scan-slots.ts`）、なくなった本棚の枠は出さない。何も選ばなければ下の段は出ない。カードを右から左へスワイプすると右に［削除］が出て、⋮の［登録を取り消す］と同じになる（指で触れたときだけ。マウスは⋮から）。取り消すと、連続設定や「持っている」で付いたものがあっても、その本はライブラリから出る（付いたものは行に残る）。取り消したカードはその回のあいだ一覧に残り、［元に戻す］でいつでも戻せる（時間で消えない）。回を終えると（完了・✕・戻る）、その回に新しく入って取り消したままの本は、ISBN があり、ほかで使っていなければ（読みたい・お気に入り・投稿・書店の棚など。一度でも使った本も残す）、本の行ごと消える（AUD-055、`src/lib/forget-books.ts`、DB の `forget_books`）。消えないと、自分の検索に「登録した本」として出て、書店の候補にも並んでいた。ライブラリから手で外した本は消さない（戻したときに状態が戻るため）。次のときは消さずに今までどおり残す: ページを閉じて回が終わった、つながっていない・保存が断られた、ほかの端末で戻してまた外した、この端末の書きかけ（飾りつけ・記録・投稿など）がその本を指している。戻すと、その本は取り消す前の状態のままライブラリに戻り、その本がもう街にないときは読み直したのと同じに送る。一括整理には、読書状況と別の行に所有状況（持っている・未所持）があり、選んだ本の「持っている」をまとめて変える。資料の未決定のうち、自由3枠の選び方、スワイプで消したあと、音を鳴らす時点、連続設定の「未指定」、再開のときの連続設定、一括整理の所有、速さの目標は、けにーさん 2026-10-19 のカード「おすすめどおり」で、ここに書いた形に決まった。音は今のまま読み取ったときに鳴らし、保存できたときの音は足さない。「未指定」は新しく入る本に読書の状態を付けない（もうある本は変えない）。速さの目標は、同じ10冊を積読家と BookTown で続けて読み、1冊あたりの間が同じか速ければ届いたとする（けにーさんの iPhone で、`?scan-timing` の［記録を写す］で測る）。2026-10-19 にけにーさんが本番で測り（新しい本14冊を約19.5秒、1冊あたり約1.4秒）、「速度はこれで十分」「積読家もこれくらい」で届いたことになった。シリーズの巻の重複・シリーズ一括登録への連続設定・シリーズの提案は、管理表6 のあとに決める。スキャンした回（資料 §2 J、けにーさん 2026-10-18 のカード「完了にも」）は、ライブラリの行の `batch_id` から回をまとめて新しい順に並べ（`src/lib/scan-history.ts`）、ライブラリの絞り込みの［スキャンした回］と、完了のまとめの［この回の本を見る］から開く（アドレスの `?batch=`）。どの端末でも同じで、本がライブラリにある間だけ残る。重複と要確認の数は読み取った端末にしかないので出さない。

## この回の棚と読み取りの音（管理表114）

- **この回の棚**（けにーさん 2026-10-23、`src/components/ScanShelf.tsx`）。上の「N冊 登録済み」のすぐ下に小さな棚を置き、読んだ本の背表紙が1冊ずつ増える。棚に並ぶのは上の数の「登録済み」と「確認中」の本だけで、数と棚はいつも合う。確認中の本は薄く、要確認と取り消した本は並ばない。背表紙の色・高さ・太さは本がもともと持つもの（書店の棚と同じ）で、まだ本の行がない本は無地。たたまずに横へ長い1本の棚で、本が増えるたびに棚が伸び、上の欄の幅いっぱいになったら古い本から左の端へ送り出す（けにーさん 2026-10-25「10冊で畳まない方が好きかも、横に長い方が良かった」。10冊ごとの音はそのまま）。字の大きさが「大きい」以上のときと、画面の高さが足りないときは数だけにする。完了の画面には、同じ本を大きな棚で出す（5段まで、それより前は「N段」）。棚は絵で、読み上げは上の数の言葉。本ごとのボタン6つ、スキャナーの「powered by Google」は変えていない。
- **読み取りの音**（けにーさん 2026-10-23、`src/lib/scan-tones.ts`）。最初の音は「コトッ」（けにーさんが試作で作った、高さ1・長さ1・間10・硬さ1）。設定の「読み取りの音」で、コトッ・木の音と響き・弾く音・ピッ（前の音）・音なしから選べ、押すとその場で鳴る。スキャナーの ♪ は今までどおりオンとオフで、オフは設定の「音なし」と同じ。オンに戻すと前に選んだ音になる。読み取ったときに鳴らすのは前と同じで、毎回わずかに高さと大きさが揺れる。新しい本でないとき（この回にもう読んだ本、ライブラリにある本）は、選んだ音にかかわらず、丸い2つの音が下がる1つの音にする（けにーさん 10-24「重複時は違う音の方がいい」。前はコトッを低くした2つで、聞き分けられなかった）。3秒以内に同じ本を読み続けたときは、前と同じく鳴らさずカードが光るだけ。棚の1段がちょうど埋まる本では、その本の音のあとに小さな3つの音が上がる（10冊の節目を、数でなく棚が埋まった手応えにする）。

## バーコードの読み取り

- **連続スキャンのバーコードの読み取り**（`src/lib/barcode-reader.ts`）。ブラウザ自身の BarcodeDetector が EAN-13 を読めればそれを使い（Android の Chrome など）、ないところ（iPhone の Safari、Windows・Linux の Chrome、Firefox）は `barcode-detector` の ponyfill で読む。中身は ZXing-C++ を WebAssembly にした `zxing-wasm` で、スキャナーを開いたときだけ読み込む。iPhone などの WebKit は、BarcodeDetector があっても読めないので使わない。パソコンでブラウザ自身のものがないときは「打つ」から始め、［カメラで読む］を押したときだけカメラを使う。
  - .wasm は外の CDN ではなく、このサイトの `/zxing/zxing_reader-<版>.wasm` から配る。ビルドと dev の前に `scripts/copy-zxing.mjs` が node_modules から `public/zxing/` に写し、barcode-detector が求める sha256 と比べる（`public/zxing/` は git に入れない。Vercel でもこのビルドを走らせるよう `vercel.json` に `buildCommand` を書いてある。Vercel では1年キャッシュ）。ライセンスの表記（ZXing-C++ の Apache-2.0 全文と、zxing-wasm・barcode-detector の MIT）は同じ場所の `LICENSE.txt` に書き出す。Apache-2.0 の全文は `scripts/licenses/` に置いてある。
  - 通信の失敗か15秒で読み込めないとき（読み取りの JavaScript と .wasm を合わせて15秒）は「読み取りの準備ができませんでした」と出して打つ入力にし、［カメラで読む］でやり直せる。読み込みの途中でスキャナーを閉じたり打つ入力に替えたりしたら、カメラはその場で止める。WebAssembly を組み立てられないブラウザ（iPhone のロックダウンモードなど）は「このブラウザはバーコードを読み取れません」。
  - **何を、いつ読むか**（2026-10-18、けにーさん）。ZXing は、カメラに見えている所すべてを読む（枠の帯だけではない。『私は積読家』と同じく、端に映ったバーコードも読む）。読むのはカメラの新しいコマごとに1回（`requestVideoFrameCallback`。ないブラウザは0.1秒ごと）で、同じ映像を読み直して iPhone を熱くしない。読んだコードは、0.6秒見えなくなるまで同じ1冊として数える（`LEAVE_MS`、`src/lib/scan.ts`。コマの速さによらないよう時間で数える）。けにーさんの iPhone で、枠の帯を0.2秒おきに読んでいたときは1冊あたり約1.5秒、見えている所すべてを休まず読むと約0.6秒（18冊で10.9秒）だった。測るときはアドレスに `?scan-timing` を付ける（`src/lib/scan-timing.ts`、`ScanTiming.tsx`）。
  - **2つの版は一緒に固定する**（package.json で `^` を付けない）。barcode-detector の JavaScript は決まった版の zxing-wasm の .wasm 向けに作られていて、zxing-wasm だけを上げると起動しない（copy-zxing がビルドを止める）。上げるときは barcode-detector の新しい版を入れ、その `dependencies` にある版に zxing-wasm をそろえ、`pnpm test:domain` と `pnpm test:library-journey`（本物の WebAssembly でカメラの本を読む確認がある）を回す。

- `book-town-scan-slots`（自由3枠、`src/lib/scan-slots.ts`）、`book-town-scan-compact`（コンパクト表示）、`book-town-scan-sound`（音を消した）と `book-town-scan-tone`（選んだ音。どちらも `src/lib/scan-tones.ts`）: この端末に1つで、アカウントごとではありません。退会でもログアウトでも消しません。
