# 書店と書店めぐり

自分の書店の店内（Scene）、店内の飾りつけ、書店めぐり（`/walk/`）と、その保存で壊してはいけないことの正本です。マイライブラリと自分で作る棚は [本棚とライブラリ.md](./本棚とライブラリ.md)、店内のどこをだれに見せるか（データベースが公開の部分を写す `public_scene_of`）は [公開範囲.md](./公開範囲.md)「店内（Scene）も同じ仕組み」、素材とフォントの出どころとライセンスは [ASSETS.md](../../public/themes/woodshop/ASSETS.md) にあります。

2026-10-22 に、`docs/CLAUDE_HANDOFF.md`（2026-10-12 の引き継ぎ）、`docs/07_書店めぐり_Phase1.md`、`docs/08_書店めぐり_Phase2.md` と docs/09「その3b」から、今も有効な決まりをここに移しました。当時の画面の写真、試し方、見た目の調整の経緯、検証の数は git の履歴にあります（例 `git show 74c6f96:docs/08_書店めぐり_Phase2.md`）。

## 目指すものと守る方針

一人ひとりが自分だけの本屋を開ける読書 SNS です。実際の書店に入って、本棚をいつまでも眺めてしまう体験を目指しています。完成イメージは、温かな照明、使い込んだ木の看板と棚、上段に正面の表紙と手書きの POP、下段に多くの背表紙とところどころの面陳、旅・日常・心などの棚札を持つ本屋です（元の画像はけにーさんが会話に添付したもので、リポジトリにはありません）。

- 本棚を主役にし、SNS のボタンは脇役にする。一般的なカード一覧に置き換えない。
- 奥行き・質感を持たせる。本を背景画像に描き込むだけで済ませない（背景の画像には背景だけを描き、本棚・本・POP は DOM で描く）。
- 本は独立して押せ、同じ本でも置く場所ごとに POP を持つ。
- 背表紙と表紙、棚札、POP を自然に組み合わせる。
- 店の表示と Book・配置・POP・Theme・Layout のデータを分ける。
- 見た目が変わっても基本の操作はそろえる。スマホの押しやすさ、読み込みとスクロールの速さを重んじる。
- 人気の集計数（いいね数など）は出さない。
- あとからテンプレート・スタンプ・編集の機能を足せる形にする。次の範囲はけにーさんの指示で決める。

## 店内の形（Scene）

- `StoreScene` は版つき（`schemaVersion` 1）の物の一覧で、家具、段、本の配置、POP、店主の POP、看板、棚札、スタンプを独立した要素として持つ。本は Book の ID を指し、同じ本を何度でも置ける。本の POP の親は配置（BookPlacement）で、Book ではない。
- 位置と大きさは親に対する割合。回転は角度で持ち、子の矩形からキャンバスの上の多角形を求める。置けない所（`forbidden`）と境界は回転込みで確かめる。家具を縮めると中を置き直し、あふれた配置は未配置へ戻す。
- `woodScene` は木の書店のはじめの配置を作るテンプレートで、段の数はこのテンプレートの値であってモデルの制約ではない。テンプレートは灯りの書店・夜の書斎・窓辺の選書の3つ（`STORE_TEMPLATES`、`src/lib/store-customization.ts`）。
- 家具を変える操作は、編集の画面から独立した関数（`src/lib/store-scene.ts`）: `addBookPlacement` → `setBookPop` で1冊と POP を作る。`moveFurniture` は家具の位置だけ、`resizeFurniture` は中を置き直す。`deleteFurniture` は本と POP を残し、本を未配置へ戻す。`placeBook` は同じ配置 ID を別の段へ移す。`setRowStyle` は段ごとの見せ方・大きさ・間を変える。変えた案は `validateScene` で確かめてから保存する。置けない所と重なる位置を、そのまま確定しない。
- 表紙のない本は、仮の装丁（`book-art.ts` の共有の絵）に書名と著者を HTML で重ねる。表紙の取り方は [本と書誌.md](./本と書誌.md)「表紙」。

## 育つ店（2026-10-25、管理表 27・28）

決定の正はリポジトリの外の「27-28_育つ書店の試作/決まったこと_2026-10-25.md」（けにーさん「めっちゃいい！」「とりあえず推奨で作ってみて、細かいところはあとで」）。ここには、コードが守っていることだけを書きます。数は作ってから調整する仮の値です。

- **読書家の店は本に合わせて育つ。** 1冊は書見台（家具の `furnitureType: "stand"`）に表紙で1冊。2冊から棚の1段になり、1段に10冊ほど（`TIER_BOOKS`）を超えるごとに同じ棚の下へ段が増え、4段まで（`GROW_MAX_TIERS`）。4段に入りきらない本は「まだ並べていない本」で待ち、消さない。見本の店は今までどおり3段の棚のまま。
- 公開の棚は、4つまでそれぞれ自分の段から始める（黒板の名前がほかの棚の本を指さないため。Claude の判断、10-25）。本の多い棚は段を多く取り、棚の本はその段に均等に分ける。
- 1段に4冊まで（`ALL_COVERS`）は全部を表紙で、真ん中に並べる（段の `align: "center"`）。入らなければ表紙のまま少し小さくする。それより多い段は表紙を3冊ほど（POP のある本と、店主が表紙を選んだ本を先に）、あとは背表紙。店主が選んだ表紙は、入るうちは表紙のまま。
- 段の形は `growingFrame`（`src/lib/growing-shop.ts`）だけが決める。段が3つまでは今の段の高さ、4段のときは少し低くして、看板の下から床の POP の上に収める。
- **飾りつけた店（`ownerManaged`）は、`growth` を持つときだけ育つ。** `growth: "auto"` は本に合わせて段を増やし（4段まで）、本が減って段の目安より2冊少なくなってから段を戻す（`SHRINK_SLACK`、境目で行ったり来たりしない）。`growth` が数（1〜4）なら、その段のまま。`growth` を持たない、育つ店より前に飾りつけた店は、今の3段のまま変えない（テンプレートを替えても）。
- **整える（店そのものが編集の画面）**: 自分の書店のページの「店を整える」で、店が画面いっぱいに開く（`ShopTidy`、けにーさん 10-25「そもそもこの画面がいらない／全部本棚を作る時の画面でいじれるのが理想」「ゲームのように直感的で視覚的」「全部ここでできるようにすればいいじゃん！」）。下に［本を足す］（公開の棚の空きに足す）［店の大きさ］［元に戻す］。本を押すと、表紙／背表紙、POP、棚から下ろす（下ろした本は「まだ並べていない本」から並べ直せる）。細い背表紙や棚札を押すと、その段の本の一覧。変えたらすぐ保存し、［元に戻す］で1つずつ戻る（画面を閉じるまで）。看板・ひとこと・棚札・黒板はまだ前の「店内を飾りつける」で直し、ここに移したら前の画面をなくす（管理表 26 の一部）。
- **店の大きさ**: 整えるの［店の大きさ］で、棚の絵（［本に合わせる］［1段］〜［4段］）を押して選ぶ（`ShopSizeChoices`、`setShopSize`）。
- **店主が手を加えた段はそのまま。** 段の本を運ぶ・下ろす・足す、表紙と背表紙を替える、棚札・黒板・段の公開を変えると、その段に `pinned` が付き、店はその段の本と順番を動かさない（非公開の段も同じ扱い）。ほかの段は店のもので、棚が変わるたびに新しい店と同じ決まりで並べ直す（`regrow`、`src/lib/growing-shop.ts`）。新しい本は手を加えていない段か、新しく増えた段に並ぶ。印は飾りつけの画面だけに出し（棚の選択の「手を加えた段」と説明）、「本に合わせて並べ直す」で店に返せる。店主が店内で下ろした本は `held` を持ち、棚が変わっても並べ直さない（手で置くと外れる）。
- **段が増えたとき**: 自分の書店の画面で「店が少し広がりました（◯段）」と知らせ、その場で「◯段のままにする」を選べる（`ShopEditor`）。飾りつけていない店でこれを選ぶと、その大きさの店内を保存する。板が伸びて灯りがさす動きはまだ（次の作業）。
- 飾りはまだ入れない（けにーさん「飾りはまだいらない」）。持ち上げて運ぶ、は次の作業。
- 1店に複数の棚の形（`src/lib/shop-layout.ts`、画面ではまだ使っていない）は3段の棚のまま。育つ店と合わせるのは 28 で。

## 書店めぐり（`/walk/`）

- 1軒ずつ、9:16 の木の書店を巡る。上下のスワイプ、ホイール、上下のキー、前後のボタンで店を替える。順番はめぐり始めたときに決めて持ち（まだ訪れていない書店が先、次に訪れたのが古い順、`startWalk`、`src/lib/walk-state.ts`）、途中で新しい店を差し込まない。終わりはなく、最後の書店の次は最初に戻って「街をひと回りしました。もう一周、どうぞ。」と知らせる。`/walk/#書店ID` で始める店を指せる。
- 本は棚の中の独立した要素。幅24px未満の背表紙は、指やマウスで押すと段を拡大し（キーボードの Enter はそのまま本を開く）、それより太い本は押すと開く。段の拡大は各段の虫眼鏡からもできる。本を手に取ると、同じ家具の上の段から下の段、左から右の順で隣の本を読める。
- 本の詳しい所では、POP だけを左右のボタンかスワイプで替えられる。本は変わらず、店主・プロフィール・書店へのリンク・スタンプ・反応が替わる。別の本へ移ると POP は最初に戻る。
- 店内はスクロールせず、詳しい所と全文の小窓だけを縦に読む。縦の店の移動、横の本の移動、POP の移動は別の範囲で受ける。小窓を開いているあいだは店を替えない。今の店だけを描き、隣の背景を先に読む。
- 訪れたことになるのは、前に出して3秒（隠れたタブの時間は除く）か、本・POP を開いたとき（`qualifiedVisit`）。
- 公開で見られるのは、公開の段と、置いてあって非公開でない本だけ（ほかの店の POP の検索も同じ）。隠した家具の子も除く。自分の店の編集のプレビューでは、自分の非公開の本も見える。

## 店内の飾りつけ

- 自分の書店だけを、`/my-shop/` の「店内を飾りつける」（`StoreSceneEditor`）で編集できる。看板、店主の言葉、棚札、黒板の見出しと絵、棚と本の公開範囲、本の追加・順番・面陳か背表紙か、POP、スタンプを変えられる。本は `useBookSearch` で探して足す。
- キャンセルは下書きを捨てる。保存に失敗したら編集の画面と下書きを開いたまま残し、保存済みの店内は変えない。

## 保存と移行で壊してはいけないこと

- **2つの保存は別々にある。** 旧保存はキー `book-town-v1`、版 1（旧 Shop・Shelf・投稿・読書など）で、変えない。書店めぐりの保存はキー `book-town-walk-v1` のまま、中身は `{schemaVersion:2, walkState, sceneOverrides, legacyBackups}`（`src/lib/walk-repository.ts`）。版 1 の中身も読み、履歴・順番・反応・店内を失わずに版 2 として扱う。知らない版や崩れた文字列は元のまま残し、上書きしない（めぐりはメモリの中で動く）。ログインした人の保存先は下の「ログインした人の保存」。
- **飾りつけた店内（`ownerManaged`、テンプレートは `templateId`。どちらも Scene の版 1 に足した任意の項目）は、その書店の書店めぐりの正本。** はじめて飾りつけるときに旧の公開の棚を配置へ写し、非公開の棚の本と POP は非公開・未配置で残す。はじめての保存が成功してから切り替え、そのときに旧 Shop の写しを `legacyBackups` に1回だけ残す。旧 Shop と旧の反応は変えない。編集し直すときに、旧の棚で店内の POP や公開の設定を上書きしない。
- **店内は棚についてくるが、棚は店内についてこない。** 飾りつけたあとも、公開の棚に並べた本は同じ棚の本が並ぶ段の最後か本のない段に入り、入りきらなければ「まだ並べていない本」で待つ（自分の本屋の画面で一言知らせる）。非公開の棚の本は未配置のまま。棚から外した本は店内の段から下がり、POP と反応を持ったまま未配置で待ち、棚とのつながり（`source`）を外すので、店主が手で並べ直せばそのまま残る。同じ本を棚に戻すと、その配置を使い直す。店主が店内で手で置いた本と、店内で下ろした本は動かさない（`followShelves`、2026-10-17、けにーさんの注釈「本棚に入れたのに書店に並ばない」）。自分の本屋の画面（`ShopEditor`）が、街と書店めぐりの保存先が同じで読めているときにだけ、これを保存する。逆向きはない: 書店のページ・プロフィール・ライブラリは棚を読み、店内での並べ替え・POP・公開の設定は棚に戻らない。
- POP の親は Book の ID ではなく配置の ID。同じ本の複数の配置を混ぜない。テンプレートを替えても、並べ替えても、配置の ID と POP の ID は変えない。
- 店内の POP への反応のキーは、端末の保存では JSON の配列 `["scene", storeId, placementId]`（`placementReactionKey`）、データベースでは `pop_reactions` の `{"scene": 置き場所のID}`。旧本棚の POP の `["棚のID","本のID"]` とは混ざらない。移すときに旧の反応を写し、店内の反応がもうあれば上書きしない。
- 段を公開するだけでは、はっきり非公開にした本を公開しない。テンプレートを替えて非公開の段から本が移っても、自動で公開しない。
- 棚から下ろす、入りきらない、家具を消す、のどれでも、本と POP を消さない。未配置の「まだ並べていない本」から戻せる。
- 保存の前に `validateScene` などで参照、境界、重なり、公開の印を確かめ、書き込みが成功してから採用する（`walk-store.ts`）。
- 確かめは `pnpm test:customization-domain`・`pnpm test:walk-domain` と、ブラウザの `pnpm test:customization`・`pnpm test:walk`・`pnpm test:street`（移し方、非公開、テンプレートの替え、並び、POP の持ち主、未配置への退避、保存の失敗、キャンセル、読み込み直し、反応の保存先、スマホでの収まり）。

## ログインした人の保存（その3b）

- **ログインしている人の店内の飾り付け、本屋への「好き」とひとこと、あとで行く本屋（保存）、POP への反応、訪問の記録は、アカウントに保存する。** 仕組みは街と同じで、差分を後ろで書き、つながらないときは送り直し、待つあいだは送り待ちの箱に置き、断られたらその1件だけ外して読み込み直す（`src/lib/supabase/sync.ts` を街と書店めぐりで共通に使う。docs/09「その3で決めたこと」）。断られた店主へのひとことの言葉は、まだ書きかけに戻せない（ひとことには書きかけの入れ物がない）。
- **書店めぐりの途中位置（どこまでめぐったか）は、その端末にだけ覚える**（localStorage、アカウントごと）。お知らせの既読と同じ扱い。
- **ひとことは店主に届く。** 店主の「自分の本屋」のページに「届いたひとこと」として並び、お知らせにも出る。読めるのは店主と書いた人だけ。1つの本屋に1人1通で、書き直すと上書き、空にして届けると取り消し。上限2000文字。店主か書いた人のどちらかがブロックすると、店主からは見えなくなる。
- **Supabase の設定がないビルド（手元の開発など）のデモは、今までどおりブラウザの中だけ。** ひとことも「送信されないデモ」のまま。

## 主なコード

- `src/lib/store-scene.ts`: 家具→段→配置→POP の形、位置と回転、確かめ（`validateScene`）と置き直し。
- `src/lib/store-scene-adapter.ts`: 棚からはじめの店内を作り、読む順と公開の POP を作る。
- `src/lib/growing-shop.ts`: 育つ店の段の形、段への本の分け方、1段の並べ方、段を足すこと。
- `src/lib/store-customization.ts`: テンプレート、移し方、公開用の店内、棚についてくる（`followShelves`）、POP・順番・未配置の編集。
- `src/lib/walk-state.ts`・`walk-repository.ts`・`walk-store.ts`: めぐる順と履歴と途中位置、端末の保存、保存に成功した店内だけを採る共有の状態。
- `src/components/WalkView.tsx`・`StoreCanvas.tsx`・`ShelfZoom.tsx`・`BookInHand.tsx`・`StoreSceneEditor.tsx`: 書店めぐりの画面、店内の描画、段の拡大、本を手に取った所、飾りつけ。
